## W2366. Task Creation & Assignment from HQ

| Field | Detail |
|---|---|
| **Trigger** | HQ function creates task for stores |
| **Frequency** | ~100–200 tasks/week across all HQ functions |
| **Volume** | ~400–800 tasks/month to 200 stores |
| **Owner** | HQ Function Manager |
| **Participants** | HQ Function Mgr, VP Store Operations, Store Manager |

### Steps

| # | Activity | Role (R) | Role (A) | Duration |
|---|---|---|---|---|
| 1 | HQ Manager creates task: description, assigned stores (all/regional/specific), priority, category, deadline, required evidence (photo/checkbox/form), responsible role at store | HQ Function Mgr | VP Store Operations | 15–30 min |
| 2 | System pushes to assigned stores; Store Manager acknowledges and assigns to responsible staff; system tracks status (assigned/in-progress/completed/overdue) | System / Store Manager | HQ Function Mgr | Automated + 10 min |

### System Touchpoints
- Task-management platform (links to VS-63 / W571 store-comms) — the task creation, assignment, and status tracking
- Store Manager app (links to VS-75) — the task-receiving and assignment channel
- Routing/targeting (links to VS-29 / W299 store-cluster) — the all/regional/specific targeting

### Pain Points / Risks
- **Task-overload risk**: HQ functions each create tasks without awareness of the cumulative volume, overwhelming stores; mitigated by the W2378 information-overload assessment and the task-volume coordination (VP Store Operations visible on total task load)
- **Vague-task risk**: a task with a vague description ("clean up the aisle") produces inconsistent execution; mitigated by the W2370 standardized task templates with clear steps and evidence requirements

### Automation Opportunity
- Task auto-created from the template (W2370); assignment auto-targeted; status auto-tracked

### Controls
- CTL-199 (ensure store-communication task closure.)
- Operational: VP Store Operations task-volume oversight; HQ Function Manager priority-discipline

### Time Estimate
~20 min/task × ~150/week + Store Manager acknowledgment absorbed = **~200 hours/month** HQ Function Managers distributed.

## W2367. Store-Level Task Execution & Reporting

| Field | Detail |
|---|---|
| **Trigger** | Store receives task assignment |
| **Frequency** | ~400–800 tasks/month |
| **Volume** | ~2–4 tasks/store/week |
| **Owner** | Store Manager |
| **Participants** | Regional Ops Manager, Store Staff, HQ Function Mgr |

### Steps

| # | Activity | Role (R) | Role (A) | Duration |
|---|---|---|---|---|
| 1 | Store Manager reviews task requirements; assigns to appropriate Department Supervisor or staff member; sets internal deadline ahead of HQ deadline | Store Manager | Regional Ops Mgr | 10–15 min |
| 2 | Staff executes task; documents completion with required evidence (photo, form, confirmation); submits via store manager app; Store Manager reviews and approves before submission to HQ | Store Staff / Store Manager | HQ Function Mgr | Varies by task |

### System Touchpoints
- Task-management platform (links to VS-63 / W571, VS-75 app) — the task execution and evidence submission
- Store Manager app (links to VS-75) — the submission and approval channel
- Evidence capture (photo/form) — the completion documentation

### Pain Points / Risks
- **Deadline-miss risk**: a task slips past the deadline because of store-ops priority conflicts; mitigated by the internal-deadline-ahead-of-HQ in step 1 and the W2369 Regional follow-up
- **Evidence-fraud risk**: a store submits stale/fabricated evidence; mitigated by the timestamp/geo-tag on photos and the W2371 quality audit

### Automation Opportunity
- Evidence auto-timestamped/geo-tagged; status auto-updated on submission

### Controls
- CTL-419 (ensure controlled execution — Store Task Assignment & Compliance Tracking (PA-63.2).)
- Operational: Store Manager approval-before-submission (step 2); Regional Ops Mgr oversight

### Time Estimate
~12 min/triage + execution varies × ~3 tasks/store/week × 200 stores = **~1,500–2,000 hours/month** Store teams (absorbed into store-ops).

## W2368. Task Compliance Dashboard

| Field | Detail |
|---|---|
| **Trigger** | Real-time; weekly review |
| **Frequency** | Continuous; weekly deep review |
| **Volume** | 200 stores; ~400–800 active tasks/month |
| **Owner** | Store Operations Director |
| **Participants** | VP Store Operations, COO |

### Steps

| # | Activity | Role (R) | Role (A) | Duration |
|---|---|---|---|---|
| 1 | Dashboard: task completion rate by store, region, and function; overdue tasks highlighted; compliance score trending; non-responsive stores flagged for Regional Ops follow-up | System / VP Store Operations | COO | 30 min/day + 2–3 hours/week |

### System Touchpoints
- Analytics/BI (links to VS-28 / W113, VS-63 / W571 task platform) — the compliance dashboard
- Store-performance scorecard (links to VS-07 / W67) — the compliance score as a Store Manager KPI
- Alerting (links to VS-27 / W380) — the overdue/non-responsive auto-flag

### Pain Points / Risks
- **Dashboard-noise risk**: the dashboard shows every task equally, drowning the critical ones; mitigated by the priority-segmented view and the overdue-foregrounding
- **Compliance-without-quality risk**: a store completes tasks (high compliance rate) but the quality is poor (rushed execution); mitigated by the W2371 quality audit alongside the rate metric

### Automation Opportunity
- Dashboard auto-refreshed; overdue/non-responsive auto-flagged for Regional Ops

### Controls
- CTL-199 (ensure store-communication task closure.)
- Operational: VP Store Operations daily/weekly review; COO escalation on chronic non-compliance

### Time Estimate
~30 min/day + ~2.5 hours/week ≈ ~125 + ~130 hours = **~255 hours/year** VP Store Operations.

## W2369. Regional Operations Follow-Up

| Field | Detail |
|---|---|
| **Trigger** | Store has overdue or non-compliant tasks |
| **Frequency** | Daily; ~20–30 overdue tasks/week |
| **Volume** | ~20–30 overdue follow-ups/week |
| **Owner** | Regional Operations Manager |
| **Participants** | Regional Ops Manager, VP Store Operations |

### Steps

| # | Activity | Role (R) | Role (A) | Duration |
|---|---|---|---|---|
| 1 | Regional Ops Manager contacts Store Manager for overdue tasks; determines root cause (staffing, training, system issue); provides support or escalates to HQ | Regional Ops Mgr | VP Store Operations | 15–30 min/store |

### System Touchpoints
- Task platform / overdue (links to VS-63 / W571, W2368 dashboard) — the overdue-task worklist
- Field-audit/follow-up tooling (links to VS-177 field-retail) — the Regional Ops follow-up channel
- Store-performance (links to VS-07 / W67) — the chronic-non-compliance pattern

### Pain Points / Risks
- **Follow-up-fatigue risk**: the same stores are chronically overdue, and Regional Ops follow-up becomes routine without resolving the root cause; mitigated by the root-cause determination in step 1 and the escalation for chronic cases
- **Punitive-only-follow-up risk**: follow-up is perceived as punitive, eroding Store Manager trust; mitigated by the support-orientation (root cause + support, not just enforcement)

### Automation Opportunity
- Overdue-task worklist auto-routed to Regional Ops; root-cause-category auto-tracked for pattern analysis

### Controls
- CTL-419 (ensure controlled execution — Store Task Assignment & Compliance Tracking (PA-63.2).)
- Operational: VP Store Operations chronic-case escalation review

### Time Estimate
~20 min/store × ~25/week ≈ ~500 min/week ≈ **~36 hours/month** Regional Ops Managers distributed.

- Template library centrally governed; format-variants auto-derived from the master

### Controls
- CTL-419 (ensure controlled execution — Store Task Assignment & Compliance Tracking (PA-63.2).)

## W2371. Task Completion Quality Audit

| Field | Detail |
|---|---|
| **Trigger** | Monthly quality spot-check |
| **Frequency** | Monthly; ~50 completed tasks audited |
| **Volume** | ~50 tasks/month |
| **Owner** | Regional Operations Manager |
| **Participants** | Regional Ops Manager, VP Store Operations |

### Steps

| # | Activity | Role (R) | Role (A) | Duration |
|---|---|---|---|---|
| 1 | Regional Ops Manager audits a sample of completed tasks (photo evidence vs. actual store condition on a follow-up visit, or documentation review); scores quality on a rubric; provides feedback | Regional Ops Mgr | VP Store Operations | Monthly |

### System Touchpoints
- Task platform / evidence (links to VS-63 / W571, W2367) — the submitted evidence
- Field-audit (links to VS-177 field-retail audit, VS-55 / W2174 planogram-compliance pattern) — the in-person verification
- Quality scorecard (links to VS-07 / W67) — the quality-audit score as a Store Manager KPI

### Pain Points / Risks
- **Compliance-vs-quality-divergence risk**: a store has high completion rate but low quality (rushed/check-box execution); mitigated by the quality audit catching the divergence
- **Sample-size-limitation risk**: auditing 50 of ~600 monthly tasks is a small sample; mitigated by the risk-based sample (high-volume stores, high-stakes task types) and the chronic-quality-issue escalation

### Automation Opportunity
- Sample auto-selected (risk-based); quality-score auto-fed to the scorecard

### Controls
- CTL-338: auditor independence — Regional Ops not the task creator; operational: VP Store Operations quality-trend review

### Time Estimate
~4 hours/month Regional Ops = **~50 hours/year** per Regional Ops Manager.

### System Touchpoints

- Calendar auto-assembled from the seasonal planogram/promo/training dependencies; collision auto-detected

### Controls
- CTL-419 (ensure controlled execution — Store Task Assignment & Compliance Tracking (PA-63.2).)
- Operational: Merchandising Planner calendar sign-off; VP Store Operations load-check

### Time Estimate
~1.5 days/season × 6 = **~70–90 hours/year** Merchandising Coordinator.

## W2373. Task Analytics & Process Improvement

| Field | Detail |
|---|---|
| **Trigger** | Monthly analytics; quarterly improvement review |
| **Frequency** | Monthly analytics; quarterly review |
| **Volume** | 200 stores; ~400–800 tasks/month |
| **Owner** | Analytics Manager |
| **Participants** | VP Store Operations |

### Steps

| # | Activity | Role (R) | Role (A) | Duration |
|---|---|---|---|---|
| 1 | Analytics Manager analyzes the task data: completion rate, on-time rate, quality score by function/category/store; identifies systemic bottlenecks (a task type with chronically low completion) and recommends process fixes | Analytics Manager | VP Store Operations | Monthly + quarterly |

### System Touchpoints
- Analytics/BI (links to VS-28 / W113, VS-63 / W571 task platform) — the task-performance dataset
- Process improvement (links to VS-133 / OpEx process mining) — the systemic-bottleneck analysis
- Task templates (links to VS-63 / W2370) — the fix applied to the template when the analysis identifies a task-design issue

### Pain Points / Risks
- **Metric-without-action risk**: the analytics surface bottlenecks but no one fixes them; mitigated by the quarterly improvement review requiring a fix-decision per finding
- **Blame-the-store risk**: the analysis attributes low completion to store failure when the root cause is task-design (vague template, unrealistic deadline); mitigated by the task-design lens in the analysis

### Automation Opportunity
- Analytics auto-refreshed; chronic-bottleneck auto-flagged for the quarterly review

### Controls
- CTL-419 (ensure controlled execution — Store Task Assignment & Compliance Tracking (PA-63.2).)
- Operational: Analytics Manager methodology sign-off; VP Store Operations quarterly-improvement-review sign-off

### Time Estimate
~6 hours/month + ~4 hours/quarter = **~90–110 hours/year** Analytics Manager.
