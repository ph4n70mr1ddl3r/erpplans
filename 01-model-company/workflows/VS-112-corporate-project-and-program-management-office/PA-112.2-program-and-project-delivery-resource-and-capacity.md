## W3553. Project Manager Assignment, Resource & Capacity Planning

| Field | Detail |
|---|---|
| **Trigger** | Project approval (W3551); portfolio cycle (W3547) |
| **Frequency** | Per project + portfolio capacity |
| **Volume** | PM/resource pool across the portfolio |
| **Owner** | PMO / Resource Owners |
| **Participants** | PMO, HR/Resource Management (links to VS-19/VS-103), Project Managers, Department Heads, Finance (links to VS-40) |

### Steps

| # | Activity | Role (R) | Role (A) | Duration |
|---|---|---|---|---|
| 1 | PMO/HR assign the Project Manager and core team per project (W3551): match PM capability to project type/size, confirm availability vs other commitments (capacity), and negotiate resource commitment with department heads; manage internal vs external/contractor PMs (links to VS-98) | PMO / HR / Department Heads | PMO Director | Per project |
| 2 | PMO maintain the enterprise resource/capacity view: PM and specialist resource pool, utilization/allocation across active projects/programs (links to W3549), forecast demand from the pipeline (W3546/W3547), and identify capacity gaps; balance load to avoid over-allocation | PMO / HR | PMO Director | Continuous |
| 3 | PMO/HR address capacity gaps: hire/contract (links to VS-19.1/VS-98), reallocate, defer projects (W3547), or partner/vendor (links to VS-34.2); report resource utilization and capacity risk to governance (W3550/W3552) | PMO / HR | PMO Director / COO | Continuous |

### System Touchpoints
- Resource/capacity (links to VS-103.3/W3562); HR (links to VS-19); contingent workforce (links to VS-98); service provider (links to VS-34.2); PMIS (links to W3562)

### Pain Points / Risks
- **Over-allocation risk**: Resources spread too thin across projects; mitigated by capacity planning
- **PM-capability-mismatch risk**: Wrong PM for the project type; mitigated by capability matching


### Automation Opportunity
- System auto-assign of "assign the Project Manager and core team per project" (replaces manual Step 1).
- System auto-capture of "enterprise resource/capacity view" (replaces manual Step 2).
- System auto-allocate of "allocate, defer projects" (replaces manual Step 3).

### Controls
operational: capacity planning; operational: capability matching

### Time Estimate
- Per project + continuous capacity

## W3554. Project Planning, Scheduling & WBS Management

| Field | Detail |
|---|---|
| **Trigger** | Project charter (W3551); stage-gate plan |
| **Frequency** | Per project + maintained |
| **Volume** | All projects |
| **Owner** | Project Manager |
| **Participants** | Project Manager, Team, PMO, Sponsor, Contractors/Vendors (links to VS-03/VS-34), Delivery-domain leads (links to VS-20/VS-27/etc.) |

### Steps

| # | Activity | Role (R) | Role (A) | Duration |
|---|---|---|---|---|
| 1 | Project Manager develop the project plan: work-breakdown-structure (WBS), activities, durations, dependencies, milestones, critical path, resources (W3553), and the baseline schedule; integrate with the delivery-domain plan (e.g., construction links to VS-20/W3480, IT links to VS-27/W132 SDLC) | Project Manager / Team | Sponsor / PMO | Per project |
| 2 | Project Manager maintain and update the schedule: track progress vs baseline, manage slippage/critical-path, re-forecast, and communicate changes (W3556/W3559); manage contractor/vendor schedules (links to VS-03/VS-34) and integrate to the program (W3549) | Project Manager | Sponsor / PMO | Continuous |
| 3 | PMO review schedule health across the portfolio (on-time %, critical-path risk, slippage), enforce planning discipline, and feed to dashboards (W3552) and stage-gates (W3548); capture planning lessons (W3560) | PMO | PMO Director | Monthly |

### System Touchpoints
- PMIS/scheduling (links to W3562); delivery-domain (links to VS-20/VS-27/VS-109/etc.); vendor (links to VS-03/VS-34); program (links to W3549); dashboards (links to W3552)

### Pain Points / Risks
- **Critical-path-slippage risk**: Late critical activities delay the project; mitigated by critical-path management
- **Plan-staleness risk**: Outdated schedule misleads; mitigated by update discipline


### Automation Opportunity
- System auto-schedule of "schedule" (replaces manual Step 1).
- System auto-track of "track progress vs baseline, manage slippage/critical-path, re-forecast, and…" (replaces manual Step 2).
- System auto-review of "review schedule health across the portfolio" (replaces manual Step 3).

### Controls
operational: critical-path management; operational: update discipline

### Time Estimate
- Per project + continuous

|---|---|---|---|---|

- System auto-report of "report project and portfolio cost performance" (replaces manual Step 3).

### Controls
operational: cost control and change management (W3556); operational: commitment tracking (links to VS-40)

| # | Activity | Role (R) | Role (A) | Duration |
|---|---|---|---|---|
