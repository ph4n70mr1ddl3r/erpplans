## Overview

Trade-In, Buy-Back & Certified Pre-Owned / Refurbished Product Resale workflows for BuildRight
Depot Corp. — owning the enterprise **circular trade-in and certified-resale discipline** by which
BuildRight takes back used/pre-owned power tools, appliances, and equipment from customers (trade-in
toward new purchase, or buy-back), inspects and refurbishes them to a certified standard, and resells
them as certified pre-owned — extending product life, capturing a price-sensitive segment, and
advancing the circular-economy/ESG agenda.

Today this discipline is **unowned as a program**. "Trade-in", "buy-back", "pre-owned", and
"second-hand" appear in 0–10 PA files as incidental references (a returns note in VS-32, a circular
mention in VS-73), and in **zero** PA files as dedicated workflow headers / **zero** value-stream
directory names. No value stream owns the end-to-end **trade-in/certified-resale discipline**: program
design & economics, trade-in valuation & pricing engine, the take-back workflow at store/counter,
inspection & grading, refurbishment/service-center processing, certification & warranty, resale
listing/pricing/fulfillment, the certified-pre-owned customer offer, and analytics (trade-in-driven
new-purchase lift, refurbishment cost/yield, resale margin, circular-economy impact).

This is distinct from **VS-32 (Returns & Reverse Logistics)** which handles *defective/wrong*
returns for refund/exchange — this value stream handles *voluntary used-product take-back for
resale*. It is distinct from **VS-73 (Waste & Circular Economy)** which manages *end-of-life
disposal/recycling* — this value stream manages *reuse/resale of still-usable product*. It is
distinct from **VS-12.1 (Installation & Repair Services / service center)** which *repairs for the
owning customer* — this value stream *refurbishes for resale* (it leverages the VS-12 service-center
capability). It is distinct from **VS-05.3 (Inventory Disposition)** which disposes of BuildRight's
*own unsold/damaged stock* — this value stream acquires *customer-owned used product* for resale. It
is distinct from **VS-09 (In-Store Services)** which serves the customer — this value stream creates
a *resale product line*.

BuildRight's exposure is structural: power tools, appliances, and equipment (profile §6.2 — ~3,500
hand tools, ~1,750 power tools, ~1,750 appliances) have residual value and a price-sensitive
secondhand market in the Philippines; a trade-in program drives new-purchase attach (customers trade
old toward new), captures the budget/price-sensitive segment with certified pre-owned, differentiates
on sustainability (links to VS-25/VS-73 ESG), and creates a circular revenue stream. The gap analysis
(§6) explicitly flagged "used-material marketplace" as a future capability — this value stream
activates that capability in a BuildRight-charter-consistent way (certified resale, not an open
C2C marketplace). Refurbishment economics and warranty-liability are the key risks.
