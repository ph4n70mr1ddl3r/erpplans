## W3073. Centralized Kit Build (DC) Work Order & Assembly Execution

| Field | Detail |
|---|---|
| **Trigger** | Build plan / kit replenishment requirement |
| **Frequency** | Per build cycle |
| **Volume** | Pre-packaged kits built at 4 DCs |
| **Owner** | DC Operations Manager |
| **Participants** | DC Ops, WMS, Inventory Control, Quality |

### Steps

| # | Activity | Role (R) | Role (A) | Duration |
|---|---|---|---|---|
| 1 | DC Ops/WMS generates kit-build work order per build plan (W3069); allocates and picks components per BOM (W3066) | DC Ops / WMS | DC Operations Manager | Per build |
| 2 | DC assembly staff build kits per work order; package, label, and apply kit SKU barcode; stage finished kits to saleable inventory | DC Assembly Staff | DC Operations Manager | Per build |
| 3 | WMS/Inventory Control confirms component consumption and finished-kit receipt; updates kit and component inventory; closes work order | WMS / Inventory Control | DC Operations Manager | Per build |

### System Touchpoints
- WMS kit-build work order (links to VS-04); component consumption; kit SKU receipt

### Pain Points / Risks
- **Build-error risk**: Wrong components/quantities in finished kit; mitigated by WMS-directed picking and QC (W3075)


### Automation Opportunity
- auto-generate (dc ops/wms generates kit-build work order)
- auto-update (finished-kit receipt; updates kit and component)

### Controls
operational: WMS-directed picking and QC (W3075)
### Time Estimate
- Per build cycle

## W3077. Kit Inventory Reconciliation, Variance & Shrinkage Control

| Field | Detail |
|---|---|
| **Trigger** | Cycle count / variance event |
| **Frequency** | Continuous + cycle counting |
| **Volume** | Kit and component inventory across DCs/stores |
| **Owner** | Inventory Control Manager |
| **Participants** | Inventory Control, DC Ops, Store Ops, LP |

### Steps

| # | Activity | Role (R) | Role (A) | Duration |
|---|---|---|---|---|
| 1 | Inventory Control cycle counts kit and component stock; reconciles system vs. physical; investigates variances (missing kit, missing component, built-but-unreceipted) | Inventory Control | Inventory Control Manager | Per cycle |
| 2 | DC/Store Ops correct variances: post adjustments with approval, rebuild/re-tear to reconcile, and document root cause | DC Ops / Store Ops | DC Operations Manager / Store Manager | Per variance |
| 3 | LP investigates shrinkage patterns (component theft, kit pilferage); escalates to VS-23; tracks kit shrink vs. target (<1.5%) | Loss Prevention | LP Manager | Periodic |

### System Touchpoints
- Cycle counting (links to VS-05/W6); inventory adjustment approval; LP analytics (links to VS-23)

### Pain Points / Risks
- **Variance risk**: Kit/component mismatch distorts inventory and availability; mitigated by cycle counting and genealogy


### Automation Opportunity
- auto-count (control cycle counts kit and component)
- auto-document (reconcile, and document root cause)
- auto-escalate (kit pilferage); escalates to vs-23; tracks)

### Controls
operational: cycle counting and genealogy
### Time Estimate
- Per cycle

## W3080. Build Capacity, Labor & Throughput Planning

|---|---|
| **Trigger** | Build plan / capacity review |
| **Frequency** | Per build cycle + seasonal |
| **Volume** | DC build capacity vs. demand |
| **Owner** | DC Operations Manager |
| **Participants** | DC Ops, Supply Chain, HR/Labor Planning, Finance |

### Steps

| # | Activity | Role (R) | Role (A) | Duration |
|---|---|---|---|---|
| 1 | DC Ops forecasts build labor hours from build plan and standard times; balances against DC pick/ship labor capacity (links to W34/PA-19.3) | DC Ops | DC Operations Manager | Per cycle |
| 2 | Supply Chain/DC Ops sequence builds to smooth workload and avoid peak pick contention; prioritize high-margin/high-velocity kits | Supply Chain / DC Ops | DC Operations Manager | Per cycle |
| 3 | HR/Labor Planning adjusts labor to build demand (seasonal ramp, overtime, temps); Finance monitors build labor cost vs. value | HR / Finance | DC Operations Manager | Per cycle |

### System Touchpoints
- Labor planning (links to W34/VS-19); build schedule; labor cost analytics (links to VS-28)

### Pain Points / Risks
- **Capacity-bottleneck risk**: Build labor competes with pick/ship labor at peak; mitigated by sequencing and labor balancing


### Automation Opportunity
- auto-forecast (dc ops forecasts build labor hours)
- auto-monitor (temps); finance monitors build labor cost)

### Controls
operational: sequencing and labor balancing
### Time Estimate
- Per cycle
