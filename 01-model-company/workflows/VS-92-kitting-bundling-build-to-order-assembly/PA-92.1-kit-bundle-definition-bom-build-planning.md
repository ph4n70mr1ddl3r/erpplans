## W3065. Kit & Bundle Product Strategy, Definition & Lifecycle

| Field | Detail |
|---|---|
| **Trigger** | Category strategy or gap/opportunity identified |
| **Frequency** | Seasonal + event-driven |
| **Volume** | Kit/Bundle item type (model company §6.4); seasonal programs |
| **Owner** | Merchandising Category Manager |
| **Participants** | Category Mgr, Merchandising Planning, Marketing, Supply Chain |

### Steps

| # | Activity | Role (R) | Role (A) | Duration |
|---|---|---|---|---|
| 1 | Category Manager identifies kit/bundle opportunities (contractor combo packs, bathroom/kitchen complete sets, tool sets, seasonal starter kits) from basket analysis and customer input | Category Manager | Merchandising Director | Per season |
| 2 | Merchandising Planning defines kit type: pre-packaged kit (built at DC/vendor), virtual bundle (price-only, components sold together), or display bundle (assembled at store) | Merchandising Planning | Merchandising Director | Per kit |
| 3 | Merchandising/Marketing approve kit concept, target customer, channel (in-store/ecommerce), and lifecycle (seasonal vs. evergreen); document strategy | Merchandising / Marketing | Merchandising Director | Per kit |

### System Touchpoints
- Merchandising/assortment planning (links to VS-01); basket analytics (links to VS-28)

### Pain Points / Risks
- **Demand-misjudgment risk**: Kits built without demand tie up components; mitigated by basket analysis and test builds


### Automation Opportunity
- System auto-document of "document strategy" (replaces manual Step 3).

### Controls
- CTL-505 (ensure controlled execution — Kit Bundle Definition Bom Build Planning (PA-92.1).)
operational: basket analysis and test builds

### Time Estimate
- 1–3 weeks per kit concept

## W3066. Kit Bill of Materials (BOM), Component Mapping & Yield Definition

| Field | Detail |
|---|---|
| **Trigger** | Kit concept approved |
| **Frequency** | Per kit + BOM change |
| **Volume** | Per active kit |
| **Owner** | Merchandising Planner |
| **Participants** | Merchandising Planner, Supply Chain, IT/Master Data |

### Steps

| # | Activity | Role (R) | Role (A) | Duration |
|---|---|---|---|---|
| 1 | Merchandising Planner defines BOM: component SKUs, quantities, substitute components, and yield (kits per component set); validates component availability | Merchandising Planner | Merchandising Planning Manager | Per kit |
| 2 | Supply Chain validates component sourcing and lead time; flags single-source constraints; confirms build feasibility across DCs | Supply Chain | Supply Chain Planning Manager | Per kit |
| 3 | IT/Master Data configures kit BOM in ERP (phantom vs. stocked kit); sets component linkage and consumption logic; tests cost roll-up | IT / Master Data | Master Data Manager | Per kit |

### System Touchpoints
- Kit BOM in ERP; item master (links to VS-29); cost roll-up engine

### Pain Points / Risks
- **BOM-accuracy risk**: Wrong components/quantities cause build errors; mitigated by validation and testing


### Automation Opportunity
- System auto-validate of "validates component availability" (replaces manual Step 1).
- System auto-flag of "flags single-source constraints" (replaces manual Step 2).
- System auto-log of "logic" (replaces manual Step 3).

### Controls
- CTL-505 (ensure controlled execution — Kit Bundle Definition Bom Build Planning (PA-92.1).)
operational: validation and testing

### Time Estimate
- Per kit

## W3072. Kit/Bundle Discontinuation, Liquidation & Component Recovery

| Field | Detail |
|---|---|
| **Trigger** | Kit end-of-life or poor performance |
| **Frequency** | Event-driven + seasonal phase-out |
| **Volume** | Discontinued kits |
| **Owner** | Merchandising Planning Manager |
| **Participants** | Merchandising Planning, Supply Chain, DC Ops, Pricing, Finance |

### Steps

| # | Activity | Role (R) | Role (A) | Duration |
|---|---|---|---|---|
| 1 | Merchandising Planning decides discontinuation; stops new builds and replenishment; plans sell-through of finished kits and component recovery | Merchandising Planning | Merchandising Planning Manager | Per kit |
| 2 | Pricing/Marketing execute clearance markdown on remaining kit inventory (links to VS-64); DC Ops/Store Ops clear shelf and ecommerce listing | Pricing / Marketing / DC Ops | Pricing Manager | Per kit |
| 3 | DC Ops tear down unsold kits per W3078, returning components to saleable stock; Finance reconciles write-down and component recovery value | DC Ops / Finance | DC Operations Manager | Per kit |

### System Touchpoints
- Discontinuation/clearance (links to VS-64); tear-down order (W3078); inventory recovery

### Pain Points / Risks
- **Stranded-inventory risk**: Kits and components left unsold post-discontinuation; mitigated by sell-through plan and tear-down recovery


### Automation Opportunity
- System auto-reconcile of "reconciles write-down and component recovery value" (replaces manual Step 3).

### Controls
- CTL-76 (ensure kit build & component inventory integrity.)
operational: sell-through plan and tear-down recovery

### Time Estimate
- 2–6 weeks per kit
