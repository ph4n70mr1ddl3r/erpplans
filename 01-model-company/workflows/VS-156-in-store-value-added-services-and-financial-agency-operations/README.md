## Overview

In-Store Value-Added Services & Financial Agency Operations workflows for BuildRight Depot Corp. —
owning the enterprise **value-added-service (VAS) counter discipline** by which BuildRight, at its
200-store customer-service counters, operates as an accredited agency for bills payment, domestic
remittance, e-money cash-in/cash-out, and mobile load/top-up — high-frequency footfall-driving
services that complement the retail offer, deepen community relevance (especially in provincial
store communities), and earn commission revenue, while operating entirely under BSP/consumer-
protection/data-privacy rules as an agent (not a principal).

Today this discipline is **unowned as a program**. "Bills payment", "e-money", "cash-in", and
"value-added service" appear in 0–2 PA files as incidental references, and in **zero** PA files as
dedicated workflow headers / **zero** value-stream directory names. No value stream owns the
end-to-end **financial-agency/VAS operating discipline**: the VAS product/partner portfolio (bills
payment aggregators, remittance/e-money principals, telco load), accreditation/licensing (BSP
agent-of-operator/principal rules), counter operations (transaction processing, cash handling,
identity/KYC), settlement & reconciliation (principal settlement, float, commission), compliance
(BSP consumer protection, AML/KYC VS-86, data privacy VS-91, cash reporting), fraud/risk, and
analytics (footfall, commission, cost-to-serve, basket-linkage).

This is distinct from **VS-80 (Payment Operations/Acquirer)** which owns *BuildRight's own
merchandise payment rail* (card/e-wallet for retail sales) — this value stream owns *third-party
financial-service agency* (paying others' bills, remitting, loading e-money). It is distinct from
**VS-08.2 (Payment & Cash Management)** which handles *in-store retail cash* — this value stream
handles *agency cash flows* (bills-payment/remittance cash) with separate settlement/reconciliation.
It is distinct from **VS-86 (AML/ABC)** which owns the *AML program* — this value stream *executes*
KYC/AML at the agency counter as an agent of the principal. It is distinct from **VS-142 (COD)** which
collects BuildRight's own cash — this value station collects *customer transaction cash for third-party
services*. It is distinct from **VS-154 (Construction-Loan Brokerage)** which is *project financing* —
this value stream is *everyday micro-financial services*.

BuildRight's exposure is structural: 200 provincial stores serving communities where bills-payment,
remittance, and e-money/load services are high-demand footfall drivers; ~600 POS / customer-service
counters with existing cash handling (VS-08.2); a trust/community brand ("Home Building Partner");
and a commission-revenue + basket-linkage opportunity. But financial-agency operations carry BSP
regulatory exposure (consumer protection, AML), cash-settlement/reconciliation risk, fraud risk, and
data-privacy obligations — the dedicated discipline that makes this a compliant, profitable,
footfall-driving service is genuinely unowned.
