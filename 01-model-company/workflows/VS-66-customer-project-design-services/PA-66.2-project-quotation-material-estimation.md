## W2438. Project Sales Order Processing

| Field | Detail |
|---|---|
| **Trigger** | Customer approves quotation |
| **Frequency** | ~300–450 project orders/month |
| **Volume** | ~300–450/month; avg project value PHP 200K–1M |
| **Owner** | Project Consultant |
| **Participants** | Project Consultant, Store Manager, Finance |

### Steps

| # | Activity | Role (R) | Role (A) | Duration |
|---|---|---|---|---|
| 1 | Project Consultant converts approved quotation to sales order: links all materials to SKUs, confirms pricing, sets delivery schedule, allocates inventory from store/DC; deposit verified | Project Consultant | Store Manager | 1–2 hours |
| 2 | Finance validates deposit payment; system reserves inventory; generates pick lists for store/DC; project entered into project tracking system with milestones | Finance / System | Project Consultant | 30 min |

### System Touchpoints
- Order management (links to VS-08 / W536 unified order management, VS-60 / W2286 routing)
- Project/design (links to VS-11 / W58 corporate account, VS-66 / W211 design)
- Analytics/BI (links to VS-27 / W113)

### Pain Points / Risks
- **Scope-creep risk**: the project scope expands beyond the original quotation, eroding margin; mitigated by the change-order process and the scope-confirmation sign-off
- **Data-quality risk**: incomplete or inaccurate master data (pricing, inventory, customer) corrupts the workflow output; mitigated by the master-data governance (VS-29 / W291) and the periodic audit

### Automation Opportunity
- Material-takeoff auto-computed from the project dimensions; quotation auto-generated from the takeoff × pricing; project-status auto-tracked from milestone completion

### Controls
- CTL-428 (ensure controlled execution — Project Quotation & Material Management (PA-66.2).)
- operational: Project Consultant sign-off on the workflow output

### Time Estimate
- ~1–2 hours per occurrence
- Volume: ~300–450/month; avg project value PHP 200K–1M
- Frequency: ~300–450 project orders/month
- Absorbed into the Project Consultant role; not incremental headcount unless volume scales significantly.

| # | Activity | Role (R) | Role (A) | Duration |

## W2443. Project Payment Collection & Milestone Billing

| Field | Detail |
|---|---|
| **Trigger** | Project milestone completed; payment due |
| **Frequency** | ~600–900 milestone payments/month (2–3 per project) |
| **Volume** | ~600–900/month |
| **Owner** | Finance Analyst |
| **Participants** | Finance Analyst, Project Consultant, Customer |

### Steps

| # | Activity | Role (R) | Role (A) | Duration |
|---|---|---|---|---|
| 1 | System generates milestone invoice upon milestone completion sign-off; Project Consultant collects payment; Finance tracks project payment status: deposit, progress payments, final payment | System / Project Consultant / Finance Analyst | Finance Manager | 30 min per milestone |

### System Touchpoints
- Pricing/financials (links to VS-17 / W9 financial close, VS-29 / W289 pricing master)
- Project/design (links to VS-11 / W58 corporate account, VS-66 / W211 design)
- Analytics/BI (links to VS-27 / W113)

### Pain Points / Risks
- **Credit-default risk**: a trade account defaults on extended credit, creating a bad-debt write-off; mitigated by the credit-scoring model and the credit-limit monitoring
- **Quote-accuracy risk**: estimated quantities diverge from billed actuals (takeoff error, site-condition change), eroding margin and customer trust; mitigated by the post-project estimate-vs-actual reconciliation feeding takeoff-factor updates

### Automation Opportunity
- Material-takeoff auto-computed from the project dimensions; quotation auto-generated from the takeoff × pricing; project-status auto-tracked from milestone completion

### Controls
- CTL-185: duplicate-invoice/billing guard on milestone billing; Operational: Finance Analyst sign-off on the workflow output

### Time Estimate
- ~30 min per occurrence
- Volume: ~600–900/month
- Frequency: ~600–900 milestone payments/month (2–3 per project)
- Absorbed into the Finance Analyst role; not incremental headcount unless volume scales significantly.
