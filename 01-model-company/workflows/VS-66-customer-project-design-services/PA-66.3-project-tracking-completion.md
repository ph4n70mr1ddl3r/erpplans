## W2446. Project Dashboard & Status Tracking

| Field | Detail |
|---|---|
| **Trigger** | Continuous project monitoring |
| **Frequency** | Continuous; ~300–450 active projects |
| **Volume** | ~300–450 active projects/month |
| **Owner** | Project Consultant |
| **Participants** | Project Consultant, Store Manager, VP Sales |

### Steps

| # | Activity | Role (R) | Role (A) | Duration |
|---|---|---|---|---|
| 1 | System maintains project dashboard: status (design/procurement/delivery/installation/completion), milestones, payment status, open issues; Consultant updates daily | System / Project Consultant | VP Sales | 30 min/day |

### System Touchpoints
- Project/design (links to VS-11 / W58 corporate account, VS-66 / W211 design)
- Analytics/BI (links to VS-28 / W113 BI platform, W231 QBR dashboard)

### Pain Points / Risks
- **Scope-creep risk**: the project scope expands beyond the original quotation, eroding margin; mitigated by the change-order process and the scope-confirmation sign-off
- **Data-quality risk**: incomplete or inaccurate master data (pricing, inventory, customer) corrupts the workflow output; mitigated by the master-data governance (VS-29 / W291) and the periodic audit

### Time Estimate
- ~30 per occurrence
- Volume: ~300–450 active projects/month
- Frequency: Continuous; ~300–450 active projects
- Absorbed into the Project Consultant role; not incremental headcount unless volume scales significantly.

### Automation Opportunity
- Dashboard auto-refreshed from source systems; anomalies auto-flagged; report auto-distributed to stakeholders

### Controls
- CTL-51 (master-data quality — links to VS-29 / W291); Operational: Project Consultant sign-off on the workflow output
