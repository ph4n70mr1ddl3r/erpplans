## Overview

Home Construction Finance, Loan Brokerage & Mortgage Referral Services workflows for BuildRight
Depot Corp. — owning the enterprise **customer construction-finance enablement discipline** by
which BuildRight, as "Your Home Building Partner," connects home-building/renovation customers
(B2C homeowners and B2B trade) to construction-loan and mortgage financing through a brokerage/
referral model — without BuildRight itself becoming a lender (which its retail charter and the
General Banking Act prohibit), but capturing the financing-led basket, accelerating project
start/completion, and earning referral economics.

Today this discipline is **unowned as a program**. "Construction loan", "home loan", and
"mortgage" appear in only 1–6 PA files as incidental references (a consumer-credit adjacency in
VS-38, a financing mention in VS-13/VS-66), and in **zero** PA files as dedicated workflow headers
/ **zero** value-stream directory names. No value stream owns the end-to-end **construction-finance
brokerage discipline**: financing-product design (construction-loan, home-equity, Pag-IBIG/end-user
financing, bank housing loans), the lender/partner network (banks, Pag-IBIG, financing companies),
brokerage/origination setup & licensing (BSP/SEC where applicable), the customer-finance
assessment & pre-qualification, loan origination & underwriting handoff, the
BuildRight↔lender↔contractor draw linkage (progress financing tied to construction milestones
VS-66/VS-12), closing & disbursement, referral economics/commission, compliance (BSP, Consumer
Act, data privacy), and analytics (conversion lift, basket size, referral revenue, default
correlation).

This is distinct from **VS-38 (Consumer Credit & Financing)** which is BuildRight's *in-house
store credit/BNPL* — this value stream is *third-party construction-loan/mortgage brokerage &
referral*. It is distinct from **VS-16 (Order-to-Cash/AR)** which bills trade accounts — this value
stream *connects customers to external lenders* who then pay BuildRight for materials/services. It
is distinct from **VS-66 (Customer Project & Design)** which designs the project — this value
stream *finances* it. It is distinct from **VS-12 (Installation)** which builds — this value
stream's draw-schedule *releases funds to* that build. It is distinct from **VS-105 (Supply Chain
Finance)** which is supplier-side — this is customer-side.

BuildRight's exposure is structural: home building/renovation is capital-constrained — many B2C
homeowners and small contractors cannot start or complete projects without financing — and
BuildRight's "Home Building Partner" positioning, its customer project/design capability (VS-66),
installation (VS-12), and B2B trade base (~5,000 accounts) make a financing-brokerage offering a
natural adjacency that lifts basket size, conversion, and project completion; referral economics
(commission 0.5–2% of loan value) on a PHP multi-billion financing flow is meaningful. The gap
analysis (§6) explicitly flagged "customer construction-loan brokerage" as a future capability to
re-evaluate — this value stream activates that capability within BuildRight's retail charter (broker/
referral, not lending).
