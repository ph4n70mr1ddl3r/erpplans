## W1638. Store-to-DC Reverse Logistics Consolidation

| Field | Detail |
|---|---|
| **Trigger** | Accumulated returns at store level reach consolidation threshold (~20 items or weekly cycle) |
| **Frequency** | Weekly per store; ~800 reverse logistics shipments/month across 200 stores |
| **Volume** | ~4 shipments/store/month |
| **Owner** | Store Manager |
| **Participants** | Store Manager, Stock Associate, DC Returns Coordinator, Logistics Coordinator |

### Steps

| # | Activity | Role (R) | Role (A) | Duration |
|---|---|---|---|---|
| 1 | Weekly: Stock Associate consolidates items in store returns staging area: (a) groups by disposition type (RTV, quality hold, damaged/defective, recall), (b) groups RTV items by vendor, (c) packs items securely with packing slip listing each item, disposition type, and original transaction reference | Stock Associate | Store Manager | 1 hour/week |
| 2 | Store Manager or Stock Associate creates reverse shipment in system: (a) selects items from returns staging inventory, (b) system generates reverse shipping order with destination DC, (c) assigns to scheduled outbound delivery truck (driver picks up returns during regular DC-to-store delivery — backhaul optimization) | Stock Associate | Store Manager | 15 min |
| 3 | Driver picks up consolidated returns from store during scheduled delivery run; signs for returned items; items enter in-transit reverse logistics tracking | Driver | Logistics Coordinator | 10 min/store |
| 4 | DC Receiving Clerk receives reverse shipment: (a) scans shipment barcode, (b) verifies items against packing slip, (c) routes items to DC returns processing area per disposition type | DC Receiving Clerk | DC Returns Coordinator | 20 min/shipment |
| 5 | System updates inventory location from store to DC; updates reverse logistics in-transit status; items remain in their disposition status (RTV, damaged, recall, etc.) | System | — | Automated |

### System Touchpoints
- Store returns staging inventory with disposition classification (W1638.1)
- Reverse shipping order creation with backhaul scheduling (W1638.2)
- In-transit reverse logistics tracking (W1638.3)
- DC receiving of reverse shipment with disposition routing (W1638.4)

### Pain Points / Risks
- **Backhaul space**: Outbound delivery trucks may be full, leaving no space for returns; requires logistics coordination or dedicated reverse pickup
- **Item condition during transit**: Returned items not properly packed may be further damaged during store-to-DC transit
- **Documentation gaps**: Missing packing slips or incomplete item lists cause delays at DC receiving

## W1639. Returns Processing Center Operations

| Field | Detail |
|---|---|
| **Trigger** | Reverse logistics shipments received at DC returns processing area |
| **Frequency** | ~800 reverse shipments/month across 4 DCs (~200/DC) |
| **Volume** | ~50 shipments/DC/week |
| **Owner** | DC Returns Coordinator |
| **Participants** | DC Returns Coordinator, DC Quality Inspector, DC Supervisor |

### Steps

| # | Activity | Role (R) | Role (A) | Duration |
|---|---|---|---|---|
| 1 | DC Returns Coordinator receives reverse shipments; sorts by disposition type: (a) RTV — route to vendor return staging per W1631, (b) Quality Hold — route to quality inspection per W1603, (c) Damaged/Defective — route to damage disposition per W91, (d) Recall — route to recall staging per W1616, (e) Resaleable — route to restock (putaway per W18) | DC Returns Coordinator | DC Supervisor | 20 min/shipment |
| 2 | For items requiring further assessment: DC Quality Inspector performs secondary quality check; determines final disposition per W1626 | DC Quality Inspector | DC Returns Coordinator | 10 min/item |
| 3 | DC Returns Coordinator updates system with final disposition for each item; inventory moved from "Returns Processing" to final status | DC Returns Coordinator | DC Supervisor | 5 min/item |
| 4 | Weekly: DC Returns Coordinator generates returns processing summary: (a) items received, processed, and dispositioned by type, (b) processing cycle time (receipt to final disposition), (c) backlog items (> 5 days unprocessed), (d) DC Supervisor reviews backlog and allocates resources | DC Returns Coordinator | DC Supervisor | 1 hour/week |

### System Touchpoints
- Returns receiving and sorting with disposition routing (W1639.1)
- Secondary quality check integration (W1639.2)
- Final disposition recording with inventory status update (W1639.3)
- Returns processing dashboard with cycle time and backlog metrics (W1639.4)

## W1640. Refurbishment & Repackaging Operations

| Field | Detail |
|---|---|
| **Trigger** | Returned item assessed as "Refurbishable" during quality assessment (W1626 or W1639) |
| **Frequency** | ~500–800 items/month eligible for refurbishment |
| **Volume** | ~125–200 per DC/month |
| **Owner** | DC Returns Coordinator |
| **Participants** | DC Returns Coordinator, DC Quality Inspector, Category Manager (pricing) |

### Steps

| # | Activity | Role (R) | Role (A) | Duration |
|---|---|---|---|---|
| 1 | DC Quality Inspector identifies refurbishable items: (a) item is functional but packaging damaged, (b) item has minor cosmetic imperfection that doesn't affect functionality, (c) item is missing minor accessories that can be replaced (screws, manual), (d) item needs cleaning or re-boxing | DC Quality Inspector | DC Returns Coordinator | 5 min/item |
| 2 | DC Returns Coordinator performs refurbishment: (a) repack in new box or rewrap, (b) replace missing accessories from spare parts inventory, (c) clean and polish, (d) apply "Refurbished" or "Open Box" label per Category Manager pricing policy | DC Returns Coordinator | DC Supervisor | 15 min/item |
| 3 | System creates refurbishment record: (a) original item linked to refurbished item, (b) refurbished item priced at discount (typically 10–20% below retail), (c) sold through specific channels: in-store clearance section, ecommerce "Open Box" category, or designated outlet store | System / Category Manager | VP Merchandising | 5 min/item |
| 4 | Monthly: DC Returns Coordinator reports refurbishment metrics: (a) items refurbished vs. scrapped, (b) recovery value (refurbished sale price minus refurbishment cost), (c) recovery rate as % of original product cost | DC Returns Coordinator | VP Supply Chain | 1 hour/month |

### System Touchpoints
- Refurbishment eligibility assessment linked to quality check (W1640.1)
- Refurbished item creation with discounted pricing (W1640.3)
- Refurbishment analytics dashboard (W1640.4)

## W1641. Returns Disposition Decision Engine & Automation

| Field | Detail |
|---|---|
| **Trigger** | Return processed through quality assessment (W1626, W1639) |
| **Frequency** | ~56,000 return dispositions/month |
| **Volume** | Automated disposition for ~70% of returns; manual review for ~30% |
| **Owner** | Quality Manager |
| **Participants** | Quality Manager, DC Returns Coordinator, Category Managers |

### Steps

| # | Activity | Role (R) | Role (A) | Duration |
|---|---|---|---|---|
| 1 | System applies automated disposition rules based on: (a) return reason code, (b) item category, (c) item condition assessment, (d) item value, (e) vendor RTV eligibility, (f) resale potential, (g) holding cost vs. recovery value | System | Quality Manager | Automated |
| 2 | Automated disposition matrix: (a) **Unwanted/wrong size + good condition → Restock**: immediate return to available inventory, (b) **Defective + vendor warranty → RTV**: route to vendor return per W1631, (c) **Damaged packaging + functional → Refurbish**: route to refurbishment per W1640, (d) **Damaged packaging + high value → Markdown**: route to markdown per W93, (e) **Safety issue → Recall hold**: route to recall process per W1615, (f) **Low value + damaged → Scrap**: route to disposal per W91, (g) **Seasonal + end of season → Liquidation**: route to liquidation per W1642 | System | Quality Manager | Automated |
| 3 | Items falling outside automated rules (exceptions) routed to DC Returns Coordinator for manual disposition with Quality Manager guidance | DC Returns Coordinator | Quality Manager | 10 min/item |
| 4 | Quarterly: Quality Manager reviews disposition decision accuracy: (a) automated disposition vs. actual outcome (did restocked items sell? were RTV credits recovered?), (b) tune rules for improved accuracy, (c) identify new disposition categories needed | Quality Manager | VP Supply Chain | 4 hours/quarter |

## W1642. Returned Product Liquidation & Channel Management

| Field | Detail |
|---|---|
| **Trigger** | Accumulated returned/dispositioned inventory designated for liquidation |
| **Frequency** | Monthly liquidation cycle |
| **Volume** | ~500–1,000 items/month across all locations |
| **Owner** | Category Manager |
| **Participants** | Category Manager, Marketing, Store Operations, DC Returns Coordinator |

### Steps

| # | Activity | Role (R) | Role (A) | Duration |
|---|---|---|---|---|
| 1 | Category Manager reviews liquidation-eligible inventory monthly: (a) returned items not resaleable at full price, (b) refurbished items (W1640), (c) damaged packaging items, (d) end-of-season clearance items | Category Manager | VP Merchandising | 2 hours/month |
| 2 | Category Manager assigns liquidation channel: (a) **In-store clearance section** — dedicated markdown area per store; priced at 30–50% discount, (b) **Ecommerce clearance** — online "Deals" section with clearance pricing, (c) **Bulk liquidation to jobbers** — sell in bulk to discount retailers or scrap buyers at 10–20% of cost, (d) **Employee sale** — periodic employee-only clearance events at deep discount, (e) **Donation** — functional items donated to community organizations (BuildRight CSR program) | Category Manager | VP Merchandising | 2 hours/month |
| 3 | System updates pricing for liquidation channel; inventory moved to clearance SKU or liquidation batch; markdown recorded in GL (inventory write-down + markdown expense) | System | Controller | Automated |
| 4 | Track liquidation sell-through: weekly monitoring of clearance inventory velocity; remaining items after 60 days moved to next liquidation tier (deeper discount or bulk sale) | Category Manager | VP Merchandising | 30 min/week |

## W1643. Reverse Logistics Carrier & Cost Management

| Field | Detail |
|---|---|
| **Trigger** | Reverse logistics shipment created (store-to-DC, DC-to-vendor, DC-to-customer) |
| **Frequency** | ~1,000–1,500 reverse logistics shipments/month |
| **Volume** | ~250–375 per DC/month |
| **Owner** | Logistics Coordinator |
| **Participants** | Logistics Coordinator, DC Returns Coordinator, Finance |

### Steps

| # | Activity | Role (R) | Role (A) | Duration |
|---|---|---|---|---|
| 1 | Logistics Coordinator manages reverse logistics carriers: (a) store-to-DC: primarily backhaul on outbound delivery trucks (lowest cost), (b) DC-to-vendor: vendor-arranged pickup (vendor cost) or BuildRight carrier (negotiate vendor reimbursement), (c) DC-to-customer (ecommerce returns): 3PL carrier (Lalamove, Transportify) | Logistics Coordinator | VP Supply Chain | 2 hours/week |
| 2 | Cost allocation: system tracks reverse logistics cost per type: (a) carrier cost for RTV shipments (chargeable to vendor where possible), (b) backhaul cost (marginal — loaded on existing route), (c) 3PL cost for ecommerce returns (BuildRight cost — factored into ecommerce cost-to-serve), (d) internal handling cost (DC Returns Coordinator labor) | System | Controller | Automated |
| 3 | Monthly: Logistics Coordinator and Controller review reverse logistics cost: (a) total cost by type, (b) cost as % of returns value, (c) carrier performance (damage rate, transit time), (d) vendor reimbursement recovery rate | Logistics Coordinator / Controller | VP Supply Chain / CFO | 1 hour/month |

## W1644. Returns Financial Analytics & Cost-to-Serve Reporting

| Field | Detail |
|---|---|
| **Trigger** | Monthly financial close cycle |
| **Frequency** | Monthly reporting; quarterly executive review |
| **Volume** | Chain-wide aggregation of returns data |
| **Owner** | Controller |
| **Participants** | Controller, Quality Manager, VP Merchandising, VP Supply Chain, CFO |

### Steps

| # | Activity | Role (R) | Role (A) | Duration |
|---|---|---|---|---|
| 1 | System aggregates monthly returns financial data: (a) total returns value by category, store, and channel, (b) return rate (% of sales by category), (c) recovery value (restock + refurbish + RTV credit + liquidation), (d) unrecoverable cost (scrap + markdown loss + handling cost), (e) reverse logistics cost (carrier + handling + refurbishment), (f) cost-to-serve per return (total returns cost ÷ number of returns) | System | Controller | Automated |
| 2 | Controller reviews returns financial report: (a) net return cost as % of gross revenue (target: < 1.5%), (b) trend analysis (monthly, quarterly, YoY), (c) top 10 SKUs by return cost, (d) top 10 stores by return rate, (e) recovery rate by disposition type | Controller | CFO | 2 hours/month |
| 3 | Quarterly: Controller presents returns financial analytics to executive team: (a) total returns cost impact on margin, (b) root cause analysis linking return reasons to quality/vendor/category issues, (c) recommendations: vendor quality improvement, product specification changes, packaging improvements, policy changes | Controller | CFO | 2 hours/quarter |
| 4 | Cross-functional action planning: VP Merchandising, VP Supply Chain, and Quality Manager review top return drivers and implement corrective actions: (a) vendor quality improvement (W1610), (b) product specification or packaging changes, (c) customer education (improved product information, how-to guides), (d) return policy adjustments for specific categories | VP Merchandising / VP Supply Chain | CEO | 2 hours/quarter |

### System Touchpoints
- Returns financial data aggregation from POS, ecommerce, warehouse, and finance modules (W1644.1)
- Returns cost-to-serve calculation (W1644.1)
- Returns financial dashboard with trend and root cause analysis (W1644.2)
- Integration with vendor quality (W1608), product content (W50), and loss prevention (W1628) analytics
