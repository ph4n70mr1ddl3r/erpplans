## W2246. In-Store Coupon Redemption

| Field | Detail |
|---|---|
| **Trigger** | Customer presents coupon at POS |
| **Frequency** | ~50K–80K/month during campaigns |
| **Volume** | ~50K–80K/month; ~15% of transactions |
| **Owner** | Cashier |
| **Participants** | Store Manager |

### Steps

| # | Activity | Role (R) | Role (A) | Duration |
|---|---|---|---|---|
| 1 | Cashier scans the coupon barcode or enters the code; system validates (active, eligible SKU, min-spend met, not-expired, per-customer-limit); applies the discount; logs the redemption for vendor reconciliation and liability reduction | Cashier / System | Store Manager | 30 sec–1 min |

### System Touchpoints
- POS / coupon (links to VS-08 / W5B, W539 coupon processing) — the redemption validation and discount application
- Coupon platform (links to VS-58 / W2238) — the coupon master for validation
- Liability (links to VS-58 / W2241) — the liability reduction on redemption

### Pain Points / Risks
- **Invalid-coupon-friction risk**: a valid coupon is rejected (system error, eligibility mis-check), frustrating the customer; mitigated by the manager-override on verified-valid coupons
- **Redemption-logging-failure risk**: the redemption isn't logged, so the vendor reconciliation and liability are wrong; mitigated by the atomic redemption-and-log transaction

### Automation Opportunity
- Redemption fully automated (scan → validate → apply → log); manager-override on verified-valid

### Controls
- CTL-44 (redemption/liability integrity); CTL (coupon-fraud — links to W2249); operational: Store Manager daily-close review

### Time Estimate
~45 sec/redemption × ~65,000/month = **~480 hours/month Cashier** (absorbed into checkout).

### System Touchpoints
- Ecommerce / coupon (links to VS-10 / W11, VS-58 / W2238, W539) — the online redemption

- Fraud filter (links to VS-125 / W266) — the code-abuse detection

- **Code-sharing-fraud risk**: a single promo code is shared on a deals site, used by thousands beyond the intended audience; mitigated by the per-customer-limit and the unique-code design

### Automation Opportunity
- Redemption fully automated; liability real-time across channels

### Controls
- CTL-44 (omnichannel liability integrity); CTL (ecommerce fraud — links to VS-125); operational: Ecom Ops Manager monitoring

### Time Estimate
Automated; Ecom Ops ~2 hours/week = **~100 hours/year**.

## W2250. Coupon Return & Reversal

| Field | Detail |
|---|---|
| **Trigger** | Customer returns item bought with coupon |
| **Frequency** | ~2K–3K/month |
| **Volume** | ~2K–3K/month |
| **Owner** | Customer Service Rep |
| **Participants** | CSA, Finance, CS Supervisor |

### Steps

| # | Activity | Role (R) | Role (A) | Duration |
|---|---|---|---|---|
| 1 | System processes the return: refunds the post-coupon price (not the full price), reverses the coupon redemption (restores the coupon if still valid, or reduces the liability if expired), adjusts the vendor reimbursement if vendor-funded | CSA / System / Finance | CS Supervisor | 5–10 min |

### System Touchpoints
- Returns (links to VS-32 / W12 returns, VS-16 / W101 refund) — the return processing
- Coupon/liability (links to VS-58 / W2241, W2246) — the coupon-reversal and liability-adjustment
- Vendor reimbursement (links to VS-58 / W2242, W2253) — the vendor-funding adjustment

### Pain Points / Risks
- **Refund-abuse risk**: a customer buys with a coupon, returns, and gets a full-price refund (pocketing the coupon value); mitigated by the post-coupon-price refund policy (system-enforced)
- **Coupon-reversal-failure risk**: the coupon isn't restored on return, so the customer loses it; mitigated by the atomic return-and-coupon-reversal transaction

### Automation Opportunity
- Return-and-coupon-reversal auto-processed; post-coupon-price refund auto-enforced

### Controls
- CTL-44 (coupon-reversal integrity); CTL (refund-accuracy — links to VS-16); operational: CS Supervisor sign-off

### Time Estimate
~7 min/case × ~2,500/month = **~290 hours/month CSR** (distributed).

## W2251. Expired Coupon Exception Handling

| Field | Detail |
|---|---|
| **Trigger** | Customer presents recently expired coupon |
| **Frequency** | ~500–1K/month |
| **Volume** | ~500–1K/month |
| **Owner** | Store Manager |
| **Participants** | Regional Ops Manager |

### Steps

| # | Activity | Role (R) | Role (A) | Duration |
|---|---|---|---|---|
| 1 | Cashier flags the expired coupon; Store Manager decides: honor as goodwill (within a defined grace window, e.g., 7 days post-expiry), or decline; system applies if honored | Store Manager | Regional Ops Mgr | 3–5 min |

### System Touchpoints
- Coupon platform (links to VS-58 / W2238) — the expiry validation
- POS (links to VS-08 / W5B) — the manager-override application
- Goodwill policy (links to VS-13 / W65 CSAT) — the customer-experience lens

### Pain Points / Risks
- **Goodwill-abuse risk**: customers learn that expired coupons are always honored, eroding the expiry discipline; mitigated by the defined grace-window (not open-ended)
- **Inconsistent-honoring risk**: one store honors, another declines, creating a fairness perception issue; mitigated by the standardized grace-window policy

### Automation Opportunity
- Grace-window auto-applied (within 7 days = auto-honor; beyond = manager-decision)

### Controls
- CTL-404 (ensure controlled execution — Coupon Redemption & Fraud Prevention (PA-58.2).)
- CTL (coupon-expiry authorization); operational: Store Manager sign-off on beyond-grace honors

### Time Estimate
~4 min/case × ~750/month = **~50 hours/month Store Manager** (distributed).

### Steps

|---|---|---|---|---|
| 1 | Finance Analyst reconciles the vendor-funded coupon redemptions: BuildRight's redemption count vs. the vendor's record; calculates the reimbursement; submits the claim; vendor validates and credits | Finance Analyst | Finance Manager | 2–3 days/month |

### System Touchpoints

- **Count-dispute risk**: the vendor disputes the redemption count; mitigated by the per-redemption evidence (the W2246 log)

### Automation Opportunity
- Reimbursement auto-calculated from the redemption log; vendor-claim auto-generated

### Controls
- CTL-39 (co-op/reimbursement accuracy); CTL-44 (count integrity); operational: Finance Manager monthly sign-off

### Time Estimate
~2.5 days/month = **~300 hours/year** Finance Analyst.
