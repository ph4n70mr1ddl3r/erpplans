## W4649. Item Cost-Master & Standard-Cost Policy Framework

| Field | Detail |
|---|---|
| **Trigger** | Cost-policy refresh; new item class; ERP setup |
| **Frequency** | Annual policy + per new item class |
| **Volume** | 1 cost-accounting policy; ~35K active SKUs across 13 categories |
| **Owner** | Cost Accounting Manager (Controller org) |
| **Participants** | Controller, Merchandising (VS-01), Master Data (VS-29), IT (VS-27/VS-113) |

### Steps

| # | Activity | Role (R) | Role (A) | Duration |
|---|---|---|---|---|
| 1 | Define the cost-element and cost-type taxonomy (material, freight-in, duty, brokerage, insurance, handling, overhead absorption), the valuation method policy (standard cost for merchandisable items; WAC at receipt per profile §6.3; actual for project/job), and the per-category overhead-absorption rules | Cost Accounting Manager | Controller | Annual |
| 2 | Configure the item cost-master: cost element breakdown, standard-cost vs. WAC flag, lot/serial cost tracking for catch-weight/cut-to-length, kit/BOM linkage, and entity/location cost segments; align with master data governance (VS-29) | Cost Accounting / Master Data / IT | Controller / CIO | Per setup |
| 3 | Publish the cost-accounting policy and the standard-cost update calendar; train merchandising/project teams on cost-data inputs and the variance-to-standard accountability model | Cost Accounting Manager | Controller | Annual |

### System Touchpoints
- Item cost-master (ERP costing module); master data governance (VS-29); GL cost elements (VS-17.1); EA standards (VS-113)

### Pain Points / Risks
- **Inconsistent-valuation risk**: Mixed standard/WAC without clear policy produces non-comparable margins across categories; mitigated by the documented valuation policy per item class
- **Overhead-absorption error risk**: Mis-applied overhead distorts unit cost and margin; mitigated by per-category absorption rules

### Automation Opportunity
- Cost-master template per item class; policy-driven cost-element defaulting; overhead-absorption engine

### Controls
- CTL-704 (ensure controlled execution — Standard-Cost Setup, Landed-Cost & Item Cost Roll (PA-158.1).)
- CTL-704: cost policy Controller-approved; cost-master changes via master-data governance (VS-29); valuation method documented per item class

### Time Estimate
- ~5–8 days annual policy + ~1–2 days per new item class

### Cross-references
- elevates W85 (VS-17.4); links to VS-29 (master data), VS-17.1 (GL), VS-113 (EA), W4656 (cost roll)

## W4650. Purchase-Price, Vendor-Quote & Should-Cost Data Aggregation

| Field | Detail |
|---|---|
| **Trigger** | Vendor contract/quote update; new SKU sourcing; periodic refresh |
| **Frequency** | Per contract/quote + quarterly refresh |
| **Volume** | ~800–1,000 vendors; ~35K SKUs; top-20 vendors = 45% of COGS |
| **Owner** | Cost Accounting Manager |
| **Participants** | Procurement (VS-03), Merchandising (VS-01), Insights (VS-44), Pricing (VS-01.2) |

### Steps

| # | Activity | Role (R) | Role (A) | Duration |
|---|---|---|---|---|
| 1 | Aggregate purchase-price inputs into the cost engine: vendor contract/quote price, price-protection claims (W161), volume-rebate estimates (VS-39, netted as a reduction of cost per W4664), and indexed/commodity-linked price clauses (VS-106) | Cost Accounting / Procurement | Controller | Quarterly + on change |
| 2 | Build **should-cost** models for key categories (steel, cement, lumber, copper, paint) from raw-material indices + conversion/overhead estimates; compare to vendor quote to surface vendor margin and negotiation opportunity | Cost Accounting / Insights / Procurement | Controller / VP Merchandising | Per category |
| 3 | Feed the validated purchase-price + should-cost data into the standard-cost build (W4656); flag SKUs where vendor price exceeds should-cost threshold for procurement action (VS-03.3) | Cost Accounting / Procurement | Controller | Quarterly |

### System Touchpoints
- Vendor contract/quote data (VS-03); rebate accrual (VS-39); price protection (W161); commodity index (VS-106); cost engine

### Pain Points / Risks
- **Stale-price risk**: A vendor price increase not flowing into the cost build understates COGS and overstates margin; mitigated by the quarterly refresh and contract-change feed
- **Rebate double-count risk**: Rebates netted as cost reduction twice (in price and again as income); mitigated by the documented netting policy (W4664)

### Automation Opportunity
- Vendor-price feed into the cost engine; commodity-index-linked should-cost models; variance-to-should-cost alerts

### Controls
- CTL-704 (ensure controlled execution — Standard-Cost Setup, Landed-Cost & Item Cost Roll (PA-158.1).)
- CTL-704: purchase-price reconciled to vendor contracts; rebate netting documented (no double-count); should-cost variances Controller-reviewed

### Time Estimate
- ~5–8 days/quarter price/should-cost aggregation across top categories

### Cross-references
- links to VS-03 (procurement), VS-39 (rebate), W161 (price protection), VS-106 (commodity), W4656 (cost roll), W4657 (PPV)

## W4651. Import Landed-Cost Build-Up: Freight, Duty, Brokerage, Insurance & Port Freight

| Field | Detail |
|---|---|
| **Trigger** | Import PO receipt (VS-02.2); duty/freight invoice; periodic landed-cost run |
| **Frequency** | Per import shipment + monthly landed-cost run |
| **Volume** | ~400–600 import TEUs/month; ~40% of COGS is imported |
| **Owner** | Cost Accounting Manager |
| **Participants** | Imports/Customs (VS-02.2/VS-87), Treasury/FX (VS-18.3), Freight (VS-110), AP (VS-15) |

### Steps

| # | Activity | Role (R) | Role (A) | Duration |
|---|---|---|---|---|
| 1 | Build the landed-cost element stack per import shipment: ocean freight, marine insurance (W191), customs duty (VS-87), brokerage, demurrage/detention (W249), port freight/drayage (W1169), and FX conversion (actual or hedged rate per W80); allocate to SKUs by value, weight, volume, or cube per category policy | Cost Accounting / Imports / Freight | Controller | Per shipment + monthly |
| 2 | Match the landed-cost elements to AP invoices (3-way, VS-15) and to the goods receipt (VS-04); post landed-cost adjustments to inventory/COGS; handle FX rate differences between hedged and actual (VS-18.3) | Cost Accounting / AP | Controller | Per shipment |
| 3 | Reconcile total landed cost to the standard landed cost (W4656) and post the landed-cost variance (W4658); analyze import-rate volatility vs. the commodity/FX hedge (VS-106/VS-18.3) | Cost Accounting | Controller | Monthly |

### System Touchpoints
- Import PO/customs (VS-02.2/VS-87); freight (VS-110); AP 3-way match (VS-15); FX/treasury (VS-18.3); landed-cost module; GL (VS-17.1)

### Pain Points / Risks
- **Mis-allocation risk**: Freight/duty allocated by an inappropriate basis (value vs. weight) distorts per-SKU landed cost (heavy/low-value tiles vs. light/high-value tools); mitigated by per-category allocation policy
- **Landed-cost timing risk**: Landed-cost elements arriving after the sale (late freight/duty invoices) require true-up; mitigated by accrual estimates and monthly reconciliation

### Automation Opportunity
- Landed-cost auto-build from AP/GR/customs data; allocation-engine per category policy; late-invoice accrual automation

### Controls
- CTL-704 (ensure controlled execution — Standard-Cost Setup, Landed-Cost & Item Cost Roll (PA-158.1).)
- CTL-704: landed-cost allocation basis documented per category; 3-way matched to AP; FX rate source governed (VS-18.3); variance analyzed monthly

### Time Estimate
- ~8–12 days/month import landed-cost across ~400–600 TEUs

### Cross-references
- links to VS-02.2/VS-87 (import/customs), VS-110 (freight), W191/W249/W1169 (freight elements), VS-18.3 (FX), W4656/W4658 (standard & variance)

## W4652. Domestic Freight, Handling & Inbound Cost Allocation to SKU

| Field | Detail |
|---|---|
| **Trigger** | Domestic inbound freight; DC handling; monthly allocation run |
| **Frequency** | Monthly |
| **Volume** | ~72,000 inbound receipts/yr; DC handling across 4 DCs |
| **Owner** | Cost Accounting Manager |
| **Participants** | Logistics (VS-06), DC Ops (VS-04), Freight (VS-110), AP (VS-15) |

### Steps

| # | Activity | Role (R) | Role (A) | Duration |
|---|---|---|---|---|
| 1 | Allocate domestic inbound freight (line-haul DC-bound, DSD), DC handling/receiving cost, and transfer freight (DC→store) to SKUs by an appropriate basis (weight, cube, case, value) per category policy; decide absorb-vs-billback posture (W4662) | Cost Accounting / Logistics | Controller | Monthly |
| 2 | Match freight/handling invoices to the receipts/shipments; post the cost to inventory or expense per the absorption policy; handle shared-shipment allocation across multiple SKUs/orders | Cost Accounting / AP / Logistics | Controller | Monthly |
| 3 | Reconcile allocated domestic freight to AP and to the standard; post domestic freight variance (W4658); identify cost-out opportunities (consolidation, routing — VS-110/VS-136) | Cost Accounting / Logistics | Controller | Monthly |

### System Touchpoints
- Freight audit/pay (VS-110.3); DC ops (VS-04); logistics (VS-06); AP (VS-15); landed/cost module; GL (VS-17.1)

### Pain Points / Risks
- **Allocation-basis risk**: Inappropriate basis distorts SKU margin (e.g., allocating handling by value over-costs cheap heavy goods); mitigated by per-category basis and periodic review
- **Billback-leakage risk**: Cost that should be billed back to vendor (compliance chargebacks W245) absorbed into COGS; mitigated by W4662 analysis

### Automation Opportunity
- Freight-invoice-to-shipment matching; allocation engine; absorb-vs-billback flagging

### Controls
- CTL-704 (ensure controlled execution — Standard-Cost Setup, Landed-Cost & Item Cost Roll (PA-158.1).)
- CTL-704: domestic-freight allocation basis documented; reconciled to AP monthly; billback opportunities flagged

### Time Estimate
- ~5–7 days/month domestic freight allocation

### Cross-references
- links to VS-06/VS-04 (logistics/DC), VS-110 (freight), W4662 (billback), W4658 (variance)

## W4653. Catch-Weight & Cut-to-Length Unit-Cost Computation (per Board-Foot / Meter / Kg)

| Field | Detail |
|---|---|
| **Trigger** | Catch-weight/cut-to-length item setup; periodic unit-cost refresh |
| **Frequency** | Per setup + periodic |
| **Volume** | Lumber (board-foot), wire/cable (meter), pipes (meter), nails/bulk (kg), tiles (sq-m); sold at 600 POS |
| **Owner** | Cost Accounting Manager |
| **Participants** | Merchandising (VS-01), Calibration (VS-115), DC Ops (VS-04), Pricing (VS-01.2) |

### Steps

| # | Activity | Role (R) | Role (A) | Duration |
|---|---|---|---|---|
| 1 | Compute the per-selling-unit cost for catch-weight/cut-to-length items from the purchase unit cost and the conversion factor (e.g., cost per board-foot from per-cubic-meter lumber cost accounting for kerf/trim loss; cost per meter from per-roll wire cost; cost per kg from per-sack bulk cost) — validated against calibrated measurement (VS-115) | Cost Accounting / Merchandising | Controller | Per setup + periodic |
| 2 | Account for fabrication yield/scrap (W169) and cutting labor where BuildRight performs the cut (VS-09.1 custom fabrication); build the unit cost into the item master and the POS pricing | Cost Accounting / Store Services | Controller | Per setup |
| 3 | Periodically re-verify conversion factors and yield assumptions against actual cut/conversion data; adjust unit cost and post variance (W4659) where yield drifts | Cost Accounting | Controller | Quarterly |

### System Touchpoints
- Catch-weight/cut-to-length module (VS-09.1/VS-115); item master (VS-29); POS pricing (VS-08); scrap inventory (W169); calibration (VS-115)

### Pain Points / Risks
- **Yield-error risk**: An outdated yield/conversion factor mis-states per-unit cost on every one of 2.8M monthly POS transactions for those items; mitigated by periodic yield re-verification (links VS-115)
- **Scrap-unaccounted risk**: Cutting scrap not built into unit cost understates COGS; mitigated by scrap-inventory tracking (W169)

### Automation Opportunity
- Conversion-factor engine; yield-from-actuals auto-update; unit-cost roll to POS pricing

### Controls
- CTL-704 (ensure controlled execution — Standard-Cost Setup, Landed-Cost & Item Cost Roll (PA-158.1).)
- CTL-704: conversion factors/yields re-verified quarterly (calibration-governed VS-115); scrap built into unit cost; per-unit cost Controller-approved

### Time Estimate
- ~per item 2–4 hours; ~3–5 days/quarter yield re-verification

### Cross-references
- links to VS-09.1 (custom fab), VS-115 (calibration), W169 (scrap), VS-01.2 (pricing), W4659 (yield variance)

## W4655. Private-Label Fully-Burdened Cost Build (COGS+, Tooling, Royalty, MOQ)

| Field | Detail |
|---|---|
| **Trigger** | Private-label product development (VS-41); cost-quote; periodic refresh |
| **Frequency** | Per PL SKU + periodic |
| **Volume** | Private-label assortment (VS-41); growing portfolio |
| **Owner** | Cost Accounting Manager |
| **Participants** | Private Label (VS-41), Procurement (VS-03), Insights/Should-cost (VS-44), Pricing (VS-01.2) |

### Steps

| # | Activity | Role (R) | Role (A) | Duration |
|---|---|---|---|---|
| 1 | Build the fully-burdened private-label cost: ex-works supplier cost + freight/duty/brokerage (W4651) + tooling/mold amortization (per unit over forecast volume) + quality-inspection cost + royalty/licence (if any) + minimum-order-quantity (MOQ) carrying cost | Cost Accounting / Private Label | Controller | Per PL SKU |
| 2 | Validate the PL cost vs. the national-brand equivalent cost and the target PL margin gap; surface tooling-amortization risk if volume underperforms forecast | Cost Accounting / Insights | Controller / VP Merchandising | Per PL SKU |

- PL product module (VS-41); should-cost (VS-44); landed cost (W4651); tooling asset amortization (VS-35); GL (VS-17.1)

### Controls
- CTL-704 (ensure controlled execution — Standard-Cost Setup, Landed-Cost & Item Cost Roll (PA-158.1).)
- CTL-704: PL cost fully burdened (tooling/royalty/MOQ); tooling amortization vs. volume monitored; PL margin gap validated vs. national brand

### Time Estimate
- ~per PL SKU 3–5 hours; ~quarterly re-roll absorbed

### Cross-references
- links to VS-41 (private label), VS-44 (should-cost), W4651 (landed cost), VS-35 (tooling asset), W4658 (variance)

## W4656. Periodic Standard-Cost Roll, Revaluation & WAC/Standard Reclass

| Field | Detail |
|---|---|
| **Trigger** | Standard-cost calendar (monthly/quarterly); material/FX/duty shift |
| **Frequency** | Periodic roll (monthly for volatile categories; quarterly standard) |
| **Volume** | ~35K active SKUs; full roll quarterly |
| **Owner** | Cost Accounting Manager |
| **Participants** | Controller, Merchandising (VS-01), Master Data (VS-29), IT (VS-27) |

### Steps

| # | Activity | Role (R) | Role (A) | Duration |
|---|---|---|---|---|
| 1 | Run the periodic standard-cost roll: pull updated purchase-price (W4650), landed cost (W4651), freight/handling (W4652), catch-weight (W4653), kit (W4654), PL (W4655); compute new standard cost per SKU per entity | Cost Accounting | Controller | Per roll |
| 2 | Post standard-cost revaluation: adjust on-hand inventory value to the new standard; post the revaluation to inventory and a cost-revaluation P&L account; handle the WAC-at-receipt to standard reclass for items under WAC | Cost Accounting / GL | Controller | Per roll |
| 3 | Publish the new standard cost to merchandising/pricing (margin impact), approve via the change-control matrix (W4670), and archive the prior standard for variance analysis (W4657/W4658) | Cost Accounting / Merchandising | Controller | Per roll |

### System Touchpoints
- Standard-cost roll engine; inventory revaluation; GL (VS-17.1); change-control (W4670); analytics (VS-28)

### Pain Points / Risks
- **Off-cycle-shift risk**: A material FX/duty shift between rolls leaves standard cost stale; mitigated by ad-hoc roll triggers for volatile categories
- **Revaluation-error risk**: Incorrect revaluation to inventory distorts the balance sheet; mitigated by Controller review and reconciliation

### Automation Opportunity
- Roll-engine consuming all cost-build workflows; auto-revaluation; margin-impact report to merchandising

### Controls
- CTL-704 (ensure controlled execution — Standard-Cost Setup, Landed-Cost & Item Cost Roll (PA-158.1).)
- CTL-704: standard roll Controller-approved; revaluation reconciled; prior standard archived for variance; change-controlled (W4670)

### Time Estimate
- ~5–7 days/quarter full standard-cost roll (+ ad-hoc rolls as triggered)

### Cross-references
- links to W4650–W4655 (cost builds), W4670 (change control), W4657/W4658 (variance), VS-17.1 (GL)
