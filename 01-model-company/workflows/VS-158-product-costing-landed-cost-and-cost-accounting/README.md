# VS-158: Product Costing, Landed-Cost & Cost Accounting

> **Finance** · [Value Stream Index](../value-stream-index.md)

---

## Overview

Product Costing, Landed-Cost & Cost Accounting workflows for BuildRight Depot Corp. — owning the
enterprise **cost-accounting discipline** by which BuildRight establishes, rolls up, analyzes, and
governers the **cost of every SKU, kit, service, project, and intercompany flow** across 5 entities
— the cost layer that sits beneath ~PHP 42–45B annual COGS, drives the 28–32% gross-margin target
and the 6–8x inventory-turn target, and feeds every pricing, assortment, markdown, project-bid, and
private-label decision.

Today this discipline is **unowned as a program**. The single workflow **W85 ("Product Costing &
Margin Analysis Review")** sits inside VS-17.4 (FP&A) and is referenced across **25 PA files**
(VS-01/VS-04/VS-11/VS-18/VS-41/VS-44/VS-92/VS-106/…) as the catch-all cost reference — yet no value
stream owns the end-to-end cost-accounting operating system: standard-cost setup and policy, import
**landed-cost build-up** (freight, duty, brokerage, insurance, port freight — ~40% of COGS is
imported), domestic freight & handling absorption, **catch-weight/cut-to-length** unit-cost
computation (lumber/board-foot, wire/meter, nails/kg — at 600 POS), **kit/BOM** cost roll-up
(VS-92), **private-label** fully-burdened cost (VS-41), periodic standard-cost roll & WAC reclass,
**purchase-price/landed-cost/production variance** analysis, gross-margin/MMU/IMU analytics, freight
duty & handling billback, **COGS reconciliation & cut-off**, **project/job costing** (VS-11/VS-46),
**service & installation costing** (VS-12), **intercompany transfer-pricing cost build** (VS-72),
cost-master governance, and costing system configuration.

This is distinct from **VS-17.4 (FP&A)** which plans and reports at the P&L level — this value
stream owns the **per-unit cost build**. It is distinct from **VS-05 (Inventory Lifecycle)** which
transacts inventory — this value stream values it. It is distinct from **VS-01.2/VS-101 (pricing &
merchandise financial planning)** which consume margin — this value stream produces the cost input
that determines it. It is distinct from **VS-106 (commodity risk)** which hedges input cost — this
value stream accounts for it. It is distinct from **VS-115 (calibration)** which ensures measurement
accuracy — this value stream turns accurate measurement into unit cost.

BuildRight's exposure is structural: at PHP 42–45B COGS, ~40% import content (with volatile freight/
duty/FX), heavy commodity exposure (steel/cement/lumber/copper), catch-weight & cut-to-length selling
across 600 POS, private-label growth (VS-41), kitting (VS-92), and large B2B/G2G project costing
(VS-11/VS-46), an inaccurate or stale cost layer directly mis-states margin, mis-prices bids,
mis-values inventory (and the PFRS inventory provision), and mis-informs every commercial decision.
