## W4497. EAS System Operations (Gates, Deactivators, Exception Alerts)

| Field | Detail |
|---|---|
| **Trigger** | Store open (VS-07.1); alarm; system health check |
| **Frequency** | Daily ops + continuous monitoring |
| **Volume** | EAS gates at all 200 store exits + deactivators at 600 POS |
| **Owner** | Loss Prevention (VS-23) / Stores (VS-07) / IT (VS-27) |
| **Participants** | IFM (VS-138), ITAM (VS-99), Auto-ID Lead |

### Steps

| # | Activity | Role (R) | Role (A) | Duration |
|---|---|---|---|---|
| 1 | Stores/LP operate EAS gates/deactivators daily (power-up test, sensitivity check, deactivator-pad function), logging health per W4485 standard | Stores / LP | Store Manager / LP Director | Daily |
| 2 | IT/LP monitor EAS exception alerts (gate triggers), classify (true alarm vs false), and route true positives to LP response (W4501) | IT / LP | LP Director | Continuous |
| 3 | IFM/IT maintain EAS hardware (gate calibration/deactivator replacement) via VS-138/VS-99, tuning sensitivity to minimize false alarms while catching real events | IFM / IT | LP Director / IFM Manager | Continuous |

### System Touchpoints
- LP/exception (VS-23); IFM maintenance (VS-138); ITAM (VS-99); POS deactivation (VS-08); service desk (VS-27.1)

### Pain Points / Risks
- **False-alarm fatigue risk**: Over-sensitive gates → ignored real alarms; mitigated by sensitivity tuning & false-alarm tracking
- **Deactivator-failure risk**: Pad fails → legitimate exit alarms & customer friction; mitigated by daily function test

### Automation Opportunity
- EAS health/alarm dashboard; false-alarm-rate analytics; auto-sensitivity tuning guidance

### Controls
- CTL-685 (ensure controlled execution — EAS/RFID Tagging, Source-Tagging & Loss-Prevention Integration (PA-151.3).)
- CTL-685: EAS daily-tested; sensitivity tuned; true alarms routed to response (W4501)

### Time Estimate
- ~15 min/day per store EAS ops; continuous monitoring

### Cross-references
- links to VS-23 (LP), VS-138 (IFM), VS-99 (ITAM), VS-08 (POS), W4485 (standard), W4501 (response)

## W4499. RFID Infrastructure, Encoding & Read-Zone Operations

| **Frequency** | Per program + continuous read-zone ops |
| **Volume** | RFID readers (handheld/fixed/smart-shelf) at RFID-enabled stores/DCs |
| **Owner** | Auto-ID Lead / IT (VS-27) / Inventory (VS-05) |
| **Participants** | DC (VS-04), Stores (VS-07), Omnichannel (VS-60), ITAM (VS-99) |

### Steps

| # | Activity | Role (R) | Role (A) | Duration |
|---|---|---|---|---|
| 1 | Auto-ID Lead/IT design/deploy RFID read-zones (DC portals, store handhelds, smart-shelf) per the W4484 policy, encode tags to the GS1 EPC standard (W4482), and integrate reads to inventory (VS-05/VS-60) | Auto-ID Lead / IT / Inventory | CIO / Inventory Manager | Per program |
| 2 | DC/Stores use RFID for cycle-counting (VS-05.1) and receiving (VS-04) — bulk scan vs line-by-line — improving count speed/accuracy toward the ≥97% target | DC / Stores / Auto-ID Lead | DC Manager / Store Manager | Continuous |
| 3 | IT/ITAM operate the RFID infrastructure (reader health, read-zone tuning, interference mgmt) via VS-99/VS-138, and feed exceptions (reads-outside-expected) to LP (VS-23) | IT / ITAM / LP | CIO / LP Director | Continuous |

- **Read-interference risk**: Metal/liquid SKUs (paint, cement, metal) degrade RFID reads; mitigated by tag-placement/reader-tuning & mixed-EAS fallback
- **Phantom-read risk**: Mis-placed tags create inventory ghosts; mitigated by read-zone validation & count reconciliation (VS-05)

### Automation Opportunity
- RFID-driven automated cycle-count; read-zone health/interference analytics; EPC auto-encoding

### Controls
- CTL-685 (ensure controlled execution — EAS/RFID Tagging, Source-Tagging & Loss-Prevention Integration (PA-151.3).)

### Time Estimate

### Cross-references
- links to VS-05 (inventory/cycle-count), VS-04 (DC), VS-60 (omnichannel), VS-99 (ITAM), VS-23 (LP), W4482/W4484 (encoding/policy)

## W4500. EAS/RFID Tag Detachment, Reuse & Reconciliation

| Field | Detail |
|---|---|
| **Trigger** | Sale completion (VS-08); return (VS-32); tag pool replenishment |
| **Frequency** | Continuous (per sale/return) |
| **Volume** | Reusable hard-tags (EAS) cycled across high-value SKUs |
| **Owner** | Stores (VS-07/VS-08) / LP (VS-23) |
| **Participants** | POS (VS-08), Returns (VS-32), Auto-ID Lead, DC (VS-04) |

### Steps

| # | Activity | Role (R) | Role (A) | Duration |
|---|---|---|---|---|
| 1 | Cashier detach/deactivate EAS hard-tags at paid sale (VS-08) using the detacher, and return reusable tags to the pool; soft-labels are deactivated | Cashier | Department Supervisor | Per sale |
| 2 | Returns (VS-32) re-apply tags to returned high-value items before restock, and reconcile tag pool counts (expected vs on-hand) per shift | Returns / Stock Associate | Store Manager | Per return/shift |
| 3 | LP/Auto-ID Lead investigate tag-pool shortages (lost/stolen tags = shrink/fraud signal), reorder pool stock (VS-34), and report shrink impact (VS-23) | LP / Auto-ID Lead | LP Director | Continuous |

### System Touchpoints
- POS detach (VS-08); returns (VS-32); LP/shrink (VS-23); procurement reorder (VS-34); DC tag pool (VS-04)

### Pain Points / Risks
- **Tag-leakage risk**: Reusable tags not returned to pool → shrink signal + replenishment cost; mitigated by shift pool reconciliation
- **Undetached-sale risk**: Tag not deactivated → exit alarm & customer friction; mitigated by detach-before-bag SOP

### Automation Opportunity
- POS-driven detach-confirmation; tag-pool count reconciliation app; shortage auto-alert to LP (VS-23)

### Controls
- CTL-150 (ensure labeling & Auto-ID data integrity.)
- CTL-685: tags detached/deactivated at paid sale; reusable pool reconciled per shift; shortages investigated (VS-23)

### Time Estimate
- ~10–20 sec/sale detach; per-shift pool count ~10 min

### Cross-references
- links to VS-08 (POS), VS-32 (returns), VS-23 (LP), VS-34 (reorder), VS-04 (DC pool), W4497 (EAS ops)
