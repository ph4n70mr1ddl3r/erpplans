## W4481. GS1 Membership, GTIN/Barcode Standard & Item-Identification Policy

| Field | Detail |
|---|---|
| **Trigger** | New SKU onboarding (VS-01.1); GS1 standard update; audit finding |
| **Frequency** | Per onboarding + annual policy review |
| **Volume** | 35,000 active SKUs + ~5–8% annual new SKUs (~1,750–2,800/yr) |
| **Owner** | Master Data / Auto-ID Lead (VS-29 linkage) |
| **Participants** | Merchandising (VS-01), IT (VS-27), Quality (VS-31), Private Label (VS-41) |

### Steps

| # | Activity | Role (R) | Role (A) | Duration |
|---|---|---|---|---|
| 1 | Auto-ID Lead maintains BuildRight's GS1 Philippines membership, Global Company Prefix (GPC), and the GTIN-assignment rule (GTIN-13/EAN for trade items, GTIN-14 for cases/pallets, GS1-128 for logistics) | Auto-ID Lead | Master Data Manager | Annual + on change |
| 2 | Auto-ID Lead assigns/validates GTIN per new SKU, governs reuse (never reuse a retired GTIN) and bundle/kit GTINs (links to VS-92), and publishes to the item master (VS-29) | Auto-ID Lead / Master Data | Master Data Manager | Per onboarding |
| 3 | Auto-ID Lead documents the item-identification policy, trains merchandising/private-label (VS-41), and audits adherence via exception reports (VS-29/W1345) | Auto-ID Lead / IT | Master Data Manager | Continuous |

### System Touchpoints
- Item master / GTIN field (VS-29/W1345); PIM (VS-137); private-label items (VS-41); quality (VS-31)

### Pain Points / Risks
- **Duplicate/reused-GTIN risk**: Two SKUs share a code → scan picks wrong item, revenue/Inventory error; mitigated by one-time-assignment rule + duplicate guard
- **Standard-drift risk**: Non-GS1 codes sneak in (vendor/private); mitigated by onboarding validation gate

### Time Estimate
- ~15 min/SKU onboarding validation; ~1 week annual policy review

### Automation Opportunity
- New-SKU GTIN auto-suggestion from GPC range; duplicate/reuse detector at item-master save; GS1 Data Hub sync

### Controls
- CTL: GTIN uniquely assigned & never reused (VS-29); GS1-standard adherence audited; private-label items gated (VS-41)

### Cross-references
- links to VS-29 (master data/W1345), VS-137 (PIM), VS-41 (private label), VS-31 (quality), VS-92 (kit GTIN), W4482 (data model)

## W4482. Item Auto-ID Data Model (GTIN, Serial, Lot/Batch, Expiry, Variable-Measure)

| Field | Detail |
|---|---|
| **Trigger** | New regulated/perishable/serial SKU; traceability requirement |
| **Frequency** | Per onboarding + on regulation change |
| **Volume** | Regulated (DTI-BPS) + DG + lot-controlled SKUs (subset of 35K) |
| **Owner** | Auto-ID Lead / Master Data (VS-29) |
| **Participants** | Quality (VS-31), Recall (VS-89), DG (VS-114), DC (VS-04) |

### Steps

| # | Activity | Role (R) | Role (A) | Duration |
|---|---|---|---|---|
| 1 | Auto-ID Lead defines which attributes ride on the identifier — serial (power tools, appliances), lot/batch (paint/chemical, cement), expiry (limited), and variable-measure (catch-weight lumber/wire/nails) per item type (profile §6.4) | Auto-ID Lead / Quality | Master Data Manager | Per onboarding |
| 2 | Auto-ID Lead maps the data model to GS1-128 application identifiers and 2D (GS1 DataMatrix / QR) for dense data (lot+expiry+serial), and to the catch-weight/random-weight barcode format (links to VS-08/W115) | Auto-ID Lead / IT | Master Data Manager | Per onboarding |
| 3 | Quality/Recall confirm the model supports recall traceability (VS-89) and DG/SDS access (VS-114); DC confirms lot/serial capture at receipt (VS-04) | Quality / Recall / DC | Master Data Manager | Per onboarding |

### System Touchpoints
- Item master attributes (VS-29); lot/serial capture (VS-04); catch-weight POS (VS-08); recall trace (VS-89); DG/SDS (VS-114)

### Pain Points / Risks
- **Traceability-gap risk**: Lot/serial not captured → recall cannot scope affected stock (VS-89); mitigated by mandatory lot/serial on regulated/DG items
- **Catch-weight error risk**: Wrong variable-measure format → wrong price at POS (links to VS-118); mitigated by validated format & W115 scale calibration

### Time Estimate
- ~20 min/SKU modeling; bulk for category batches

### Automation Opportunity
- Attribute-driven barcode-format auto-selection; lot/serial mandatory-flag from item category; catch-weight format validator

### Controls
- CTL: lot/serial mandatory on regulated/DG items (VS-89/VS-114); catch-weight format validated; recall-traceability verified

### Cross-references
- links to VS-29 (attributes), VS-04 (lot/serial receipt), VS-08 (catch-weight POS), VS-89 (recall), VS-114 (DG/SDS), VS-115 (scale calibration), W4481 (GTIN)

| **Frequency** | Per need + annual review |
| **Volume** | Label format set across hang-tag, shelf-edge, adhesive, bulk-yard, variable |
| **Owner** | Auto-ID Lead / Merchandising (VS-01.2) |
| **Participants** | Marketing (VS-14), Private Label (VS-41), PIM (VS-137), Stores (VS-07) |

### Steps

| # | Activity | Role (R) | Role (A) | Duration |
|---|---|---|---|---|
| 1 | Auto-ID Lead/Merchandising specify the label format set (hang-tag, shelf-edge label, adhesive price sticker, bulk-yard tag, variable/catch-weight label) per item type/channel, with required content fields (description, price, unit, barcode, promo, mandatory-discount notice VS-85) | Auto-ID Lead / Merchandising | Master Data Manager / VP Merch | Annual + per need |
| 2 | Auto-ID Lead/Marketing set artwork/brand standards (logo, color, font legibility, bilingual EN/Filipino, DG/SDS pictograms VS-114, DTI-BPS PS/ICC mark VS-117) and the template library in PIM (VS-137) | Auto-ID Lead / Marketing | VP Merch | Annual + per refresh |
| 3 | Auto-ID Lead/PIM govern template version control, publish to stores/DC, and audit format conformance (W4486) | Auto-ID Lead / PIM | Master Data Manager | Continuous |

### System Touchpoints
- PIM/template library (VS-137); pricing (VS-01.2); marketing brand (VS-14); DTI-BPS mark (VS-117); mandatory discount (VS-85); DG/SDS (VS-114)

### Pain Points / Risks
- **Non-compliant-label risk**: Missing PS/ICC mark, price, or DG pictogram → Consumer Act/DTI exposure; mitigated by mandatory-field template + conformance audit (W4486)
- **Format-mismatch risk**: Shelf-edge label doesn't fit fixture; mitigated by fixture-aware format spec (links to VS-55)

### Time Estimate
- ~3–5 days initial format set; ~2 days annual refresh

### Automation Opportunity
- Template-driven label auto-layout from PIM data; mandatory-field validator; fixture-aware format selection

### Controls
- CTL: label carries mandatory fields (price/unit/barcode, RA 7394; PS/ICC VS-117; DG pictogram VS-114); template version-controlled; conformance audited (W4486)

### Cross-references
- links to VS-137 (PIM), VS-01.2 (pricing), VS-14 (brand), VS-117 (PS/ICC), VS-85 (mandatory discount), VS-114 (DG/SDS), VS-55 (fixtures), W4486 (conformance)

### Steps

| # | Activity | Role (R) | Role (A) | Duration |
|---|---|---|---|---|

| 2 | Auto-ID Lead/LP set the RFID-tagging policy (RFID-enabled categories for cycle-count/smart-shelf/real-time inventory — links to VS-05/VS-60), tag type (passive UHF), and encoding standard | Auto-ID Lead / LP / IT | LP Director / CIO | Annual + on program |

### Controls
- CTL: tagging policy shrink/value-based (VS-23); RFID encoding standard; source-tag agreements (W4498)

## W4486. Barcode Quality, Read-Rate & Label-Conformance Standard

| Field | Detail |
|---|---|
| **Trigger** | Scan-fail spike; audit; standard review |
| **Frequency** | Continuous monitoring + periodic audit |
| **Volume** | Read-rate/conformance across 134.4M annual POS line scans |
| **Owner** | Auto-ID Lead / Quality (VS-31) / LP (VS-23) |
| **Participants** | IT (VS-27), Stores (VS-07), DC (VS-04), Revenue Assurance (VS-118) |

### Steps

| # | Activity | Role (R) | Role (A) | Duration |
|---|---|---|---|---|
| 1 | Auto-ID Lead/Quality define the barcode-quality grade (ISO/IEC 15416 print quality, GS1 minimum grade), the label-conformance checklist (W4483 fields), and the target read-rate (> 99.5% first-pass scan) | Auto-ID Lead / Quality | Master Data Manager / Quality Manager | Annual |
| 2 | Auto-ID Lead/IT monitor scan-fail/manual-entry rates per POS/DC (links to VS-08 exception, VS-04 receive), and flag failing barcodes/labels for reprint | Auto-ID Lead / IT | CIO | Continuous |
| 3 | Auto-ID Lead/Quality run periodic label-conformance audits in stores (RA 7394 price-tag presence/accuracy), trigger reprints/corrections, and report to Revenue Assurance (VS-118) | Auto-ID Lead / Quality / Stores | Master Data Manager / Quality Manager | Periodic |

### System Touchpoints
- POS scan-fail/exception (VS-08); DC receive exception (VS-04); revenue assurance (VS-118); quality (VS-31)

### Pain Points / Risks
- **Scan-fail risk**: Poor-grade barcode → cashier manual entry/keying error & queue friction (links to VS-118); mitigated by grade gate + reprint
- **Missing-price-tag risk**: RA 7394 violation per SKU/store; mitigated by conformance audit & reprint SLA

### Time Estimate
- ~1 week standard; ongoing monitoring + ~monthly audits

### Automation Opportunity
- Scan-fail-rate dashboard by item/POS; auto-reprint trigger on threshold; image-based label-conformance check

### Controls
- CTL: barcode-grade gate (ISO 15416); read-rate target > 99.5%; RA 7394 price-tag presence audited (W4487)

### Cross-references

## W4488. Auto-ID Change Control, Synchronization & Master-Data Handshake

| Field | Detail |
|---|---|
| **Trigger** | GTIN/format/tag change; price change; promo; system sync |
| **Frequency** | Per change (frequent — price/promo daily) |
| **Volume** | Auto-ID data changes synced POS↔ERP↔PIM↔WMS (profile §14.3) |
| **Owner** | Auto-ID Lead / IT (VS-27) / Master Data (VS-29) |
| **Participants** | Pricing (VS-01.2), Promotions (VS-58), Ecommerce (VS-10), EA (VS-113) |

### Steps

| # | Activity | Role (R) | Role (A) | Duration |
|---|---|---|---|---|
| 1 | Auto-ID Lead/IT govern change control for GTIN/barcode/format/tag data (request, approve, effective-date, rollback) and the POS↔ERP↔PIM↔WMS synchronization (profile §14.3 near-real-time) | Auto-ID Lead / IT / Master Data | CIO / Master Data Manager | Per change |
| 2 | Pricing/Promotions push price/promo changes to shelf-edge labels and POS (links to VS-01.2/VS-58), with reprint triggers and effective-time coordination (bi-monthly sale events) | Pricing / Auto-ID Lead / IT | VP Merch / CIO | Per change |
| 3 | IT/Auto-ID Lead monitor sync health (latency < 30s per profile §15.3), reconcile POS-local cache vs central, and resolve drift before it reaches the customer (links to VS-118) | IT / Auto-ID Lead | CIO | Continuous |

### System Touchpoints
- POS↔ERP sync (profile §14.3); PIM (VS-137); WMS (VS-04); pricing/promo (VS-01.2/VS-58); ecommerce (VS-10); EA (VS-113)

### Pain Points / Risks
- **Sync-drift risk**: Price/label mismatch across channels → over/under-charge (links to VS-118); mitigated by near-real-time sync + drift reconciliation
- **Uncontrolled-change risk**: GTIN reuse/format change mid-life → scan chaos; mitigated by change-control + effective-dating

### Time Estimate
- Per change minutes–hours; ongoing monitoring

### Automation Opportunity
- Change-control workflow with effective-date; automated cross-channel sync verification; drift auto-detection

### Controls
- CTL: auto-ID changes change-controlled & effective-dated; sync latency monitored (< 30s); cross-channel price/label reconciled (VS-118)

### Cross-references
- links to VS-27/VS-113 (IT/EA), VS-29 (master data), VS-01.2/VS-58 (pricing/promo), VS-10 (ecommerce), VS-118 (revenue assurance), W4481–W4483 (spec)
