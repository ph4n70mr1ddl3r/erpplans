## Overview

Global Sourcing, Import Buying & Sourcing-Agent Management workflows for BuildRight Depot
Corp. — owning the **strategic source-side of imported merchandise** across a ~40%-import
assortment: ~400 international vendors across China, Taiwan, Indonesia, Malaysia, Japan, and
Europe, ~400–600 import TEUs/month, ~PHP 1.4B/month import value (~PHP 17–18B/yr), and a
landed-cost-driven gross-margin structure (28–32% target) where import sourcing decisions
materially move COGS and availability. BuildRight's import assortment is concentrated in
commodity-intensive, value-density-varied categories (steel/cement/lumber, tiles, electrical,
paint/coatings, power tools, appliances, hardware/fasteners).

Today this discipline is **unowned as a program**: VS-02.2 executes **operational** import &
customs clearance (LC opening, broker, container tracking, duty payment), VS-03 executes
transactional vendor onboarding/PO, VS-87 governs customs/tariff compliance, VS-31/VS-41 run
quality and factory audits, and VS-106 manages commodity input-cost risk — but no value stream
owns the **strategic global-sourcing discipline**: source-market and country strategy, the
sourcing-model decision (direct vs sourcing-agent vs overseas buying office), sourcing-agent
selection/contracting/performance, overseas buying-office operations, import-vendor development
and category-level import sourcing strategy, consolidated container buying and order
consolidation, FOB/ex-works negotiation and Incoterms strategy, total-landed-cost sourcing
optimization, and supply-base geographic-risk diversification. 'global sourcing', 'sourcing
agent', 'overseas buying office', and 'ex-works' each appear in **zero** PA files.

This is distinct from **VS-02.2 (Import & Customs Operations)** which executes the operational
import transaction (LC, broker, clearance, duty) — this value stream owns the *strategic
source-side decisions* upstream of that execution. It is distinct from **VS-03 (Vendor
Management)** which runs the transactional vendor record and PO cycle for all vendors (this
value stream owns the *import-sourcing strategy and the agent/overseas-office operating model*
that is unique to imports). It is distinct from **VS-87 (Customs Trade Compliance & Tariff)**
which governs customs/tariff compliance (this value stream owns *which* countries/vendors/items
to source and the supply-base geographic strategy). It is distinct from **VS-31/VS-41 (Quality/
Private-Label)** which assures product quality (this value stream owns the *sourcing-channel and
agent/office governance* through which quality and social-compliance are enforced at source). It
is distinct from **VS-106 (Commodity & Input-Cost Risk)** which hedges commodity exposure (this
value stream owns the *physical sourcing* decisions whose pricing is informed by that hedging).
Global sourcing, import buying & sourcing-agent management is the *strategic source-side* discipline
— distinct from operational import/customs, transactional vendor/PO management, customs
compliance, quality assurance, and commodity hedging.

BuildRight's exposure is structural: ~40% of COGS is imported, the assortment is
commodity-intensive and value-density-varied, and import sourcing decisions drive landed cost,
availability, quality, lead time (45–90 days), and supply-base resilience. Without a dedicated
owner, BuildRight risks fragmented country-by-country buying, over-reliance on (or under-governance
of) sourcing agents, suboptimal consolidation and landed cost, and concentrated country/geographic
risk — risks that no existing value stream owns end-to-end.
