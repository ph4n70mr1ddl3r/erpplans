## W2945. HS Tariff Classification & AHTN Code Assignment per Imported SKU

| Field | Detail |
|---|---|
| **Trigger** | New imported SKU or classification review |
| **Frequency** | Event-driven + periodic review |
| **Volume** | ~40% of 35,000 SKUs imported; ~14,000 SKUs |
| **Owner** | Trade Compliance Specialist |
| **Participants** | Trade Compliance, Procurement, Master Data |

### Steps

| # | Activity | Role (R) | Role (A) | Duration |
|---|---|---|---|---|
| 1 | Trade Compliance assigns AHTN/HS code per SKU based on material, function, composition (General Rules of Interpretation); documents rationale | Trade Compliance Specialist | Trade Compliance Manager | Per SKU |
| 2 | Master Data configures HS code and duty rate in item master; links to origin and FTA preference eligibility | Master Data | Trade Compliance Specialist | Per SKU |
| 3 | Trade Compliance validates classification on sample basis; corrects mis-classification that over/under-pays duty | Trade Compliance | Trade Compliance Manager | Periodic |

### System Touchpoints
- Item master HS code/duty; classification rationale repository

### Pain Points / Risks
- **Compliance risk**: Wrong HS code causes duty error and BOC penalty; mitigated by GRI-based classification and validation


### Automation Opportunity
- System auto-document of "documents rationale" (replaces manual Step 1).
- System auto-validate of "validates classification on sample basis" (replaces manual Step 3).

### Controls
- CTL-238 (ensure customs classification & valuation compliance.)
- operational: GRI-based classification and validation

### Time Estimate
- 15–30 min per SKU

## W2947. Customs Valuation (Transaction Value) & Adjustments Management

| Field | Detail |
|---|---|
| **Trigger** | Each import entry |
| **Frequency** | Continuous |
| **Volume** | ~400–600 TEUs/month |
| **Owner** | Trade Compliance Specialist |
| **Participants** | Trade Compliance Manager, Treasury, Trade Compliance |
| Participants: | Trade Compliance, Procurement, Treasury |

### Steps

| # | Activity | Role (R) | Role (A) | Duration |
|---|---|---|---|---|
| 1 | Trade Compliance computes transaction value per WTO Valuation Agreement: invoice price + freight + insurance (CIF) + dutiable additions | Trade Compliance Specialist | Trade Compliance Manager | Per entry |
| 2 | Treasury captures currency conversion at BOC-prescribed rate on date of filing; validates exchange rate application | Treasury | Trade Compliance Manager | Per entry |
| 3 | Trade Compliance validates valuation method; documents alternative valuation if transaction value inapplicable | Trade Compliance | Trade Compliance Manager | Per entry |

### System Touchpoints
- Import entry valuation engine; currency conversion; documentation archive

### Pain Points / Risks
- **Compliance risk**: Under-valuation triggers BOC fraud case; mitigated by transaction-value method and documentation


### Automation Opportunity
- System auto-validate of "validates exchange rate application" (replaces manual Step 2).
- System auto-document of "documents alternative valuation if transaction value inapplicable" (replaces manual Step 3).

### Controls
- CTL-238 (ensure customs classification & valuation compliance.)
- operational: transaction-value method and documentation

### Time Estimate
- 30–60 min per entry

| **Frequency** | Event-driven |
| **Volume** | ~60–70% of imports from ASEAN/China/ROK/Japan/Australia |

### Steps

| # | Activity | Role (R) | Role (A) | Duration |
|---|---|---|---|---|

### Pain Points / Risks
- **Compliance risk**: Invalid CO triggers retroactive duty + penalty; mitigated by validation and PSR documentation


### Automation Opportunity
- System auto-validate of "validates authenticity and accuracy" (replaces manual Step 2).
- System auto-import of "import entry" (replaces manual Step 3).

### Controls
- CTL-238 (ensure customs classification & valuation compliance.)
- operational: validation and PSR documentation

### Time Estimate
- 30–60 min per shipment
