## W2801. Store Cash Office End-of-Day Skim, Denomination & Bundle Preparation

| Field | Detail |
|---|---|
| **Trigger** | End-of-day cash office close per store |
| **Frequency** | Daily per store |
| **Volume** | 200 stores; ~PHP 1.0B+ monthly cash sales |
| **Owner** | Store Cashier Lead |
| **Participants** | Cashier, Store Manager, Assistant Store Manager |

### Steps

| # | Activity | Role (R) | Role (A) | Duration |
|---|---|---|---|---|
| 1 | Cashier counts cash drawer per terminal; reconciles to POS Z-report; investigates over/short variance > PHP 500 | Cashier | Store Manager | 20–30 min/terminal |
| 2 | Cashier sorts and denominates currency by note value; straps bundles per BSP denomination standard (100 pcs/bundle); prepares deposit bag with manifest | Cashier | Store Manager | 30–45 min |
| 3 | Store Manager witnesses sealing and signs deposit manifest under dual-control; logs sealed-bag ID into smart safe or CIT deposit log | Store Manager / Cashier | Store Manager | 10 min |

### System Touchpoints
- POS Z-report; cash-office workstation; deposit manifest; smart safe

### Pain Points / Risks
- **Control risk**: Single-person handling enables theft; mitigated by dual-control witnessing and CCTV

### Time Estimate
- 60–90 min per store per day

## W2802. Smart Safe Cash Drop, Validation & CIT-Ready Flagging

| Field | Detail |
|---|---|
| **Trigger** | Cash bundle ready for deposit |
| **Frequency** | 1–3× per day per store |
| **Volume** | ~200 smart safes network-wide |
| **Owner** | Store Cashier Lead |
| **Participants** | Cashier, Store Manager, CIT Operations |

### Steps

| # | Activity | Role (R) | Role (A) | Duration |
|---|---|---|---|---|
| 1 | Cashier drops strapped bundle into smart safe; safe validates denomination/counterfeit via note reader; credits amount to store deposit account in ERP | Cashier | Store Manager | 5 min/drop |
| 2 | Smart safe transmits real-time deposit data to CIT Operations dashboard; flags "CIT-ready" once threshold (e.g., PHP 200K) reached or scheduled pickup | CIT Operations | CIT Operations Manager | Continuous |
| 3 | Store Manager reviews daily smart-safe report; reconciles to POS cash sales; investigates discrepancies; confirms pickup readiness | Store Manager | Store Manager | 15 min |

### System Touchpoints
- Smart safe note validation; CIT dashboard; ERP deposit account; POS reconciliation

### Pain Points / Risks
- **Reconciliation risk**: Counterfeit/jammed notes mis-credit; mitigated by note-reader validation and daily reconciliation

### Time Estimate
- 5 min per drop; 15 min daily reconciliation

## W2803. Mid-Day Cash Skim & Cash Drawer Threshold Management

| Field | Detail |
|---|---|
| **Trigger** | Cash drawer exceeds threshold (e.g., PHP 30K) |
| **Frequency** | 1–2× per day per terminal during peak |
| **Volume** | 600 terminals |
| **Owner** | Store Cashier Lead |
| **Participants** | Cashier, Assistant Store Manager |

### Steps

| # | Activity | Role (R) | Role (A) | Duration |
|---|---|---|---|---|
| 1 | Cashier performs mid-day skim when drawer exceeds threshold; counts excess cash; moves to smart safe/drop safe under dual-control | Cashier | Assistant Store Manager | 15–20 min |
| 2 | Assistant Store Manager validates skim amount and drawer balance; updates drawer float; returns working change | Assistant Store Manager | Store Manager | 10 min |
| 3 | Store Manager monitors per-terminal cash levels via dashboard; rebalances drawer floats across terminals to optimize checkout flow | Store Manager | Store Manager | Continuous |

### System Touchpoints
- POS drawer-level monitoring; smart safe drop log; float management

### Pain Points / Risks
- **Security risk**: Excess cash in drawer raises robbery risk; mitigated by threshold-driven skimming

### Time Estimate
- 15–20 min per skim

## W2804. CIT Pickup Schedule Planning & Store Request Management

| Field | Detail |
|---|---|
| **Trigger** | Standing schedule + ad-hoc store request |
| **Frequency** | 2–4× per week per store |
| **Volume** | ~200 stores × ~3 pickups/week ≈ 600 pickups/week |
| **Owner** | CIT Operations Manager |
| **Participants** | CIT Operations, Store Manager, CIT Vendor |

### Steps

| # | Activity | Role (R) | Role (A) | Duration |
|---|---|---|---|---|
| 1 | CIT Operations maintains standing pickup schedule per store (frequency based on cash volume tier); optimizes armored car routes by geography | CIT Operations | CIT Operations Manager | Weekly |
| 2 | Store Manager requests ad-hoc pickup via app when cash exceeds security threshold or for special events (paydays, holidays); confirms pickup window | Store Manager | CIT Operations Manager | Per request |
| 3 | CIT Operations dispatches confirmation and ETA to store; store prepares deposit; verifies armored guard identity and route manifest at handover | CIT Operations / Store Manager | CIT Operations Manager | Per pickup |

### System Touchpoints
- CIT route optimization; pickup request app; guard verification manifest

### Pain Points / Risks
- **Security risk**: Predictable pickup timing invites heist; mitigated by randomized timing and route variation

### Time Estimate
- 30 min planning/week; 15 min per pickup handover

## W2806. Counterfeit Detection, Note Authentication & Suspect Handling

| Field | Detail |
|---|---|
| **Trigger** | Suspect note detected at POS or smart safe |
| **Frequency** | Event-driven; ~20–50 notes/year |
| **Volume** | ~30 suspect events/year |
| **Owner** | Store Cashier Lead |
| **Participants** | Cashier, Store Manager, LP, BSP |

### Steps

| # | Activity | Role (R) | Role (A) | Duration |
|---|---|---|---|---|
| 1 | Cashier authenticates notes via UV/magnetic detector and tactile check; smart safe performs automated counterfeit scan on drop | Cashier | Store Manager | Per large note |
| 2 | Cashier/Store Manager sequesters suspect note; records serial, customer info, time; does not return to customer per BSP protocol; logs incident | Store Manager | Store Manager | 15–30 min |
| 3 | LP reports suspect note to BSP bank for verification; tracks outcome; if confirmed counterfeit, write-off absorbed by store LP budget | LP | LP Manager | Per event |

### System Touchpoints
- Counterfeit detector; smart safe scan; LP incident tracker; BSP reporting

### Pain Points / Risks
- **Loss risk**: Counterfeit accepted becomes store loss; mitigated by detector use and protocol training

### Time Estimate
- 15–30 min per event

## W2807. Cash Office Security, Dual-Control & CCTV Correlation

| Field | Detail |
|---|---|
| **Trigger** | Continuous; reviewed at cash-office close |
| **Frequency** | Daily + monthly audit |
| **Volume** | 200 cash offices |
| **Owner** | Store Manager |
| **Participants** | Store Manager, LP, Internal Audit |

### Steps

| # | Activity | Role (R) | Role (A) | Duration |
|---|---|---|---|---|
| 1 | Store Manager enforces dual-control (two-person) for safe access, deposit sealing, and high-value transactions; maintains access log | Store Manager | Store Manager | Continuous |
| 2 | LP ensures cash office CCTV coverage (safe, counter, deposit prep); synchronizes timestamps with POS and smart-safe events | LP | LP Manager | Continuous |
| 3 | Internal Audit reviews cash-office dual-control evidence quarterly; spot-audits CCTV-vs-deposit correlation; reports control exceptions | Internal Audit | Audit Committee | Quarterly |

### System Touchpoints
- Access control log; CCTV-LP integration; audit evidence repository

### Pain Points / Risks
- **Fraud risk**: Lapsed dual-control enables skimming; mitigated by quarterly audit and CCTV correlation

### Time Estimate
- Continuous; 1–2 days/quarter audit

## W2808. Foreign Currency & Mutilated/Soiled Note Handling

| Field | Detail |
|---|---|
| **Trigger** | Foreign or mutilated note tendered (near tourist/border stores) |
| **Frequency** | Event-driven; rare |
| **Volume** | ~5–10 events/month (select stores) |
| **Owner** | Store Cashier Lead |
| **Participants** | Cashier, Store Manager, Bank |

### Steps

| # | Activity | Role (R) | Role (A) | Duration |
|---|---|---|---|---|
| 1 | Cashier follows policy on foreign-currency acceptance (generally declined except select border/tourist stores with FX arrangement); refers customer to bank | Cashier | Store Manager | Per event |
| 2 | Cashier handles mutilated/soiled notes per BSP standard (do not reissue; segregate for bank exchange); logs for deposit annotation | Cashier | Store Manager | Per event |
| 3 | Store Manager returns mutilated notes to bank via CIT; obtains exchange credit; tracks BSP clean-note-policy compliance | Store Manager | Store Manager | Per deposit |

### System Touchpoints
- Note-segregation log; bank exchange record; BSP clean-note compliance

### Pain Points / Risks
- **Compliance risk**: Reissuing soiled notes violates BSP clean-note policy; mitigated by segregation protocol

### Time Estimate
- 10–20 min per event
